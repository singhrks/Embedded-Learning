Eigenvectors, SVD and dimensionality

Some directions survive a transformation unchanged, and some carry most of the information in a dataset. Finding them is how you compress, denoise, and understand what a matrix is really doing.

Eigenvectors: the directions that survive

Eigenvectors are usually introduced as a computation and are much easier to hold onto as a question: which directions does this transformation leave pointing the same way?

   MOST vectors change direction when a matrix acts on them.
   A FEW ONLY GET SCALED:

        A v = lambda * v

   v is an EIGENVECTOR, lambda is its EIGENVALUE.

   A = [3 1]      try v = [1, 1]:
       [1 3]           A v = [3+1, 1+3] = [4, 4] = 4 * [1,1]
                       EIGENVECTOR, eigenvalue 4

                  try v = [1, -1]:
                       A v = [3-1, 1-3] = [2, -2]
                           = 2 * [1,-1]
                       EIGENVECTOR, eigenvalue 2

                  try v = [1, 0]:
                       A v = [3, 1]  - a DIFFERENT direction.
                       Not an eigenvector.

   GEOMETRICALLY, for this A: the plane is stretched by 4
   along the [1,1] diagonal and by 2 along [1,-1]. THOSE TWO
   NUMBERS AND DIRECTIONS DESCRIBE THE ENTIRE
   TRANSFORMATION.

   WHAT THE EIGENVALUES TELL YOU:
     |lambda| > 1   that direction is AMPLIFIED
     |lambda| = 1   preserved
     |lambda| < 1   SHRUNK toward zero
     lambda < 0     flipped
     complex        rotation is involved

   AND THE REASON THIS MATTERS FOR NEURAL NETWORKS:

   APPLYING A MATRIX REPEATEDLY - which is exactly what a
   deep network, or a recurrent network unrolled over time,
   does - AMPLIFIES ALONG THE LARGEST EIGENVALUE AND KILLS
   EVERYTHING ELSE:

        A^n v  ->  dominated by lambda_max^n

     lambda_max > 1  ->  EXPLODING GRADIENTS
     lambda_max < 1  ->  VANISHING GRADIENTS

   That is not a metaphor; it is the literal mechanism
   behind why deep RNNs could not be trained (chapter 18)
   and why weight initialisation is chosen to keep the
   spectrum near 1 (chapter 15).

   EIGENDECOMPOSITION, when it exists:

        A = V diag(lambda) V^-1

   "change to the eigenbasis, scale each axis, change back."
   For SYMMETRIC matrices, V is ORTHOGONAL and this is
   always possible with real eigenvalues - which is why
   covariance matrices are so pleasant to work with.

Singular value decomposition

The SVD is the most generally useful decomposition in the subject — it works on any matrix at all — and it is the machinery behind compression, PCA and low-rank adaptation alike.

/* EIGENVECTORS ONLY EXIST NICELY FOR SQUARE MATRICES. THE
   SVD WORKS FOR ANY MATRIX AT ALL, AND IT IS THE MORE
   USEFUL TOOL.                                            */

        A  =  U  S  V^T

     A: (m, n)   any matrix
     U: (m, m)   ORTHOGONAL - output directions
     S: (m, n)   DIAGONAL, non-negative, sorted DESCENDING
                 - the SINGULAR VALUES
     V: (n, n)   ORTHOGONAL - input directions

/* THE GEOMETRIC READING, and it is complete:

     EVERY LINEAR TRANSFORMATION IS
         a ROTATION (V^T),
         then a SCALING along axes (S),
         then another ROTATION (U).

   That is all any matrix ever does. The singular values say
   how much stretching happens in each of n perpendicular
   directions.                                             */

import numpy as np

A = np.array([[3., 1.], [1., 3.], [0., 2.]])   # (3, 2)
U, s, Vt = np.linalg.svd(A, full_matrices=False)

U.shape     # (3, 2)
s           # [4.24, 1.87]   <- SORTED, DESCENDING, always
Vt.shape    # (2, 2)

# reconstruct
A_check = U @ np.diag(s) @ Vt
np.allclose(A, A_check)      # True

/* WHAT THE SINGULAR VALUES MEAN:

   · s[0] is the largest stretch factor = the SPECTRAL NORM
   · the number of NON-ZERO singular values is the RANK
     (chapter 03)
   · s[0] / s[-1] is the CONDITION NUMBER - how badly the
     matrix amplifies errors
   · a singular value of 1e-16 is numerically zero, which is
     the reliable way to compute rank

/* --- LOW-RANK APPROXIMATION: THE ECKART-YOUNG THEOREM --- */

    Keep only the k largest singular values:

        A_k = U[:, :k] @ diag(s[:k]) @ Vt[:k, :]

    THIS IS PROVABLY THE BEST RANK-k APPROXIMATION TO A, in
    the least-squares sense. Not a heuristic - optimal.

    STORAGE: k(m + n + 1) numbers instead of m*n.
    For a (4096, 4096) matrix with k = 64:
        16.8 million -> 524 thousand.  32x smaller.

/* AND THIS IS DIRECTLY WHY LoRA WORKS (chapters 03, 24).
   The empirical observation is that the WEIGHT UPDATE
   during fine-tuning has low intrinsic rank - the
   adaptation lives in a small subspace - so representing it
   as B @ A with small r loses almost nothing.

   IT IS ALSO the basis of several model-compression methods,
   of PCA below, and of classical latent semantic analysis -
   which was doing "embeddings via SVD" decades before
   neural embeddings (chapter 17).                        */

PCA: finding the directions that matter

PCA is the SVD applied with a purpose, and it is worth seeing worked through because the same reasoning reappears whenever someone talks about the effective dimension of an embedding space.

/* THE QUESTION: given data in 768 dimensions, which few
   directions capture most of the variation?             */

import numpy as np

X = np.random.randn(1000, 50)      # 1000 samples, 50 dims

# 1. CENTRE THE DATA. Not optional - PCA finds directions of
#    variance ABOUT THE MEAN, and skipping this makes the
#    first component point at the mean instead.
X_centred = X - X.mean(axis=0)

# 2. SVD OF THE CENTRED DATA
#    (More stable than eigendecomposing the covariance
#     matrix, which squares the condition number.)
U, s, Vt = np.linalg.svd(X_centred, full_matrices=False)

# 3. THE PRINCIPAL COMPONENTS ARE THE ROWS OF Vt
components = Vt[:10]               # top 10 directions

# 4. PROJECT ONTO THEM
X_reduced = X_centred @ components.T    # (1000, 10)

# 5. HOW MUCH DID WE KEEP?
variance = s**2 / (len(X) - 1)
explained = variance / variance.sum()
print(explained[:10].sum())        # e.g. 0.85 -> 85%

/* THE INTERPRETATION:
     PC1  the direction of greatest variance in the data
     PC2  the greatest remaining variance, PERPENDICULAR to
          PC1
     ... and so on. Each is orthogonal to all previous ones.

/* WHERE YOU MEET IT:
     · VISUALISATION: project 768-dimensional embeddings to
       2-D to plot them. (t-SNE and UMAP are more popular
       for this and preserve local structure better - but
       they DISTORT global distances, so never read
       cluster-to-cluster distances off a t-SNE plot.)
     · WHITENING: decorrelate and unit-scale features before
       training
     · NOISE REDUCTION: keep the top components, discard the
       tail
     · UNDERSTANDING WHAT A MODEL LEARNED: PCA of a layer's
       activations often reveals interpretable directions

/* AND THE HONEST LIMITATION: PCA IS LINEAR. It finds
   directions, not curves. Data on a spiral or a sphere has
   structure PCA cannot represent, which is precisely the
   gap that non-linear models - autoencoders, and neural
   networks generally (chapter 14) - fill.

/* --- THE POWER METHOD, because it explains a lot --- */
    def power_iteration(A, iters=100):
        v = np.random.randn(A.shape[1])
        for _ in range(iters):
            v = A @ v
            v = v / np.linalg.norm(v)   # RENORMALISE, or it
                                        # overflows
        return v, v @ A @ v             # eigenvector,
                                        # eigenvalue

    Repeatedly multiply and renormalise; converge to the
    dominant eigenvector. NOTHING BUT MATRIX-VECTOR PRODUCTS.

    THIS IS THE SAME AMPLIFICATION that causes exploding
    gradients - here used deliberately. It is also,
    essentially, PageRank. And the renormalisation step is
    exactly what normalisation layers do inside a network
    (chapter 22): stop repeated multiplication from
    diverging.                                            */
Where this actually appears in modern models 
LoRA fine-tuning        a low-rank update; ch. 24
Model compression       SVD of weight matrices
Attention analysis      SVD of the QK matrix reveals
                        what a head compares
Embedding visualisation PCA / t-SNE / UMAP; ch. 17
Gradient clipping       bounding the spectral norm
Spectral normalisation  dividing weights by s[0] to
                        stabilise training
Whitening               decorrelating inputs; ch. 15

You will rarely call np.linalg.svd in a training loop. You will constantly meet the ideas — rank, spectrum, dominant direction — in explanations of why something trains or does not.

The numerical reality

None of the above is computed the way it is written in a textbook, and the gap between the two matters the first time a decomposition returns something surprising.

/* --- DO NOT EIGENDECOMPOSE A COVARIANCE MATRIX --- */
    /* WRONG - squares the condition number */
    C = X.T @ X / n
    vals, vecs = np.linalg.eigh(C)

    /* RIGHT - SVD of the data directly */
    U, s, Vt = np.linalg.svd(X_centred)
    /* The singular values of X are the square roots of the
       eigenvalues of X^T X, so you get the same answer with
       half the numerical damage. */

/* --- SIGNS ARE ARBITRARY --- */
    If v is an eigenvector, so is -v. Different libraries,
    versions and platforms return different signs. NEVER
    WRITE A TEST THAT DEPENDS ON THE SIGN of a component;
    compare absolute values or fix a convention yourself.

/* --- ORDER IS ONLY GUARANTEED FOR SVD --- */
    np.linalg.svd returns singular values DESCENDING.
    np.linalg.eig returns eigenvalues in NO PARTICULAR
    ORDER. np.linalg.eigh (symmetric) returns them
    ASCENDING. Read the docs; assuming the wrong one silently
    selects the least important components.

/* --- COST --- */
    Full SVD of an (m, n) matrix is O(m n min(m,n)).
    For a (4096, 4096) weight matrix that is billions of
    operations - seconds, not microseconds.

    IF YOU ONLY NEED THE TOP k:
        from scipy.sparse.linalg import svds
        U, s, Vt = svds(A, k=10)          # ITERATIVE
    or randomised SVD, which is what scikit-learn's
    TruncatedSVD uses by default. Both are dramatically
    cheaper and are what production code uses.

/* --- AND A WARNING ABOUT INTERPRETATION --- */
    A large singular value means a direction with large
    VARIANCE. That is not the same as a direction that is
    IMPORTANT FOR YOUR TASK. A feature can vary enormously
    and be irrelevant; a subtle direction can be decisive.
    PCA is unsupervised - it does not know what you are
    predicting. When labels are available, methods that use
    them (LDA, or simply training a model) will find better
    directions.                                           */
