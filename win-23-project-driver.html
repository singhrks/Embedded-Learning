Project: the KMDF ring-buffer driver

A complete, working Windows driver you build, sign, install and break yourself. It needs no hardware — it installs as a software device — and it exercises queues, IOCTLs, asynchronous completion, timers, locking and the full PnP lifecycle. Deliberately the same problem as the Linux project in chapter 36, so the comparison teaches as much as the code.

What you are building

This is the first full project, and it deliberately uses nearly everything from the preceding chapters at once. Read this section before writing anything — knowing what the finished driver does makes the code far easier to hold in your head.

   \\.\RingBuf                    a software device

   WriteFile()                    push bytes into a ring
   ReadFile()                     pop bytes; BLOCKS if empty,
                                  completing asynchronously
   IOCTL_RB_GET_STATS             counters
   IOCTL_RB_RESET                 empty it
   IOCTL_RB_SET_CONFIG            capacity policy

   A periodic timer generates synthetic data, standing in for
   an interrupt - so the asynchronous completion path is real
   even without hardware.

  WHAT IT EXERCISES:
     WDF object model and contexts       (chapter 14)
     the device lifecycle                (chapter 15)
     default and manual queues           (chapter 16)
     asynchronous completion from a DPC  (chapter 11)
     IOCTL design and validation         (chapter 17)
     spinlocks and IRQL discipline       (chapters 03, 10)
     an INF and installation             (chapter 20)
     Driver Verifier and WinDbg          (chapters 22, 23)

  That is most of the track, in about 600 lines.

The files

A real driver is several files, split so that the interface applications depend on is separate from the implementation that may change freely. That separation is the ABI distinction from chapter 01 made concrete.

ringbuf\

  driver.c           DriverEntry, EvtDeviceAdd
  queue.c            the I/O callbacks
  ring.c             the buffer itself
  ringbuf.inf
  ringbuf.vcxproj
  test\
    rbtest.c         the client (chapter 26)

ringbuf.h — the shared ABI

Start with the header, because it is the part you can never change once an application uses it. Everything else in this project can be rewritten; these definitions are a promise.

#pragma once

#include <initguid.h>

// {8F3A2B1C-4D5E-6F70-8192-A3B4C5D6E7F8}
DEFINE_GUID(GUID_DEVINTERFACE_RINGBUF,
    0x8f3a2b1c, 0x4d5e, 0x6f70, 0x81, 0x92,
    0xa3, 0xb4, 0xc5, 0xd6, 0xe7, 0xf8);

#define RB_DEVICE_TYPE   0x8123

typedef struct _RB_STATS {
        UINT32 Capacity;
        UINT32 Used;
        UINT64 BytesWritten;
        UINT64 BytesRead;
        UINT64 Drops;
        UINT64 TimerTicks;
        UINT32 PendingReads;
        UINT32 Reserved[7];        /* MUST be zero */
} RB_STATS, *PRB_STATS;

typedef struct _RB_CONFIG {
        UINT32 Overwrite;          /* 0 or 1 */
        UINT32 TimerPeriodMs;      /* 0 disables the generator */
        UINT32 Reserved[6];
} RB_CONFIG, *PRB_CONFIG;

#define IOCTL_RB_GET_STATS \
    CTL_CODE(RB_DEVICE_TYPE, 0x800, METHOD_BUFFERED, \
             FILE_READ_ACCESS)

#define IOCTL_RB_RESET \
    CTL_CODE(RB_DEVICE_TYPE, 0x801, METHOD_BUFFERED, \
             FILE_WRITE_ACCESS)

#define IOCTL_RB_SET_CONFIG \
    CTL_CODE(RB_DEVICE_TYPE, 0x802, METHOD_BUFFERED, \
             FILE_WRITE_ACCESS)

#define IOCTL_RB_GET_CONFIG \
    CTL_CODE(RB_DEVICE_TYPE, 0x803, METHOD_BUFFERED, \
             FILE_READ_ACCESS)

/* NOTE the Access fields: GET_* need only read access,
   SET_* and RESET require write. The I/O manager enforces
   this before the driver sees the request (chapter 17) -
   free, correct access control.                          */

driver.c

This file is the entry point and the device lifecycle: what happens at load, at device arrival, and at each power transition. Compare it with chapter 15's sequence as you read.

#include "driver.h"

#ifdef ALLOC_PRAGMA
#pragma alloc_text (INIT, DriverEntry)
#pragma alloc_text (PAGE, RbEvtDeviceAdd)
#endif

NTSTATUS
DriverEntry(_In_ PDRIVER_OBJECT DriverObject,
            _In_ PUNICODE_STRING RegistryPath)
{
        WDF_DRIVER_CONFIG config;
        NTSTATUS status;

        WDF_DRIVER_CONFIG_INIT(&config, RbEvtDeviceAdd);

        status = WdfDriverCreate(DriverObject, RegistryPath,
                                 WDF_NO_OBJECT_ATTRIBUTES,
                                 &config, WDF_NO_HANDLE);
        if (!NT_SUCCESS(status))
                KdPrint(("ringbuf: WdfDriverCreate 0x%x\n",
                         status));

        return status;
}

NTSTATUS
RbEvtDeviceAdd(_In_ WDFDRIVER Driver,
               _Inout_ PWDFDEVICE_INIT DeviceInit)
{
        WDF_OBJECT_ATTRIBUTES attributes;
        WDF_IO_QUEUE_CONFIG queueConfig;
        WDF_TIMER_CONFIG timerConfig;
        WDFDEVICE device;
        PRB_CONTEXT ctx;
        NTSTATUS status;

        UNREFERENCED_PARAMETER(Driver);
        PAGED_CODE();

        /* buffered I/O: the framework copies user buffers for
           us, safe at any IRQL (chapter 08)                */
        WdfDeviceInitSetIoType(DeviceInit, WdfDeviceIoBuffered);

        /* who may open it (chapter 04). Administrators and
           SYSTEM only - tighten or loosen deliberately.    */
        {
                DECLARE_CONST_UNICODE_STRING(sddl,
                        L"D:P(A;;GA;;;SY)(A;;GA;;;BA)");
                status = WdfDeviceInitAssignSDDLString(
                                DeviceInit, &sddl);
                if (!NT_SUCCESS(status))
                        return status;
        }

        WDF_OBJECT_ATTRIBUTES_INIT_CONTEXT_TYPE(&attributes,
                                                RB_CONTEXT);
        attributes.EvtCleanupCallback = RbEvtDeviceCleanup;

        status = WdfDeviceCreate(&DeviceInit, &attributes,
                                 &device);
        if (!NT_SUCCESS(status))
                return status;

        ctx = RbGetContext(device);
        ctx->Device        = device;
        ctx->Capacity      = RB_DEFAULT_CAPACITY;
        ctx->TimerPeriodMs = 100;
        ctx->Overwrite     = TRUE;

        /* the ring itself - NON-PAGED, because the timer DPC
           touches it at DISPATCH_LEVEL (chapter 07)        */
        ctx->Buffer = (PUCHAR)ExAllocatePool2(
                        POOL_FLAG_NON_PAGED,
                        ctx->Capacity, RB_POOL_TAG);
        if (ctx->Buffer == NULL)
                return STATUS_INSUFFICIENT_RESOURCES;

        /* a lock, parented to the device (chapter 14) */
        WDF_OBJECT_ATTRIBUTES_INIT(&attributes);
        attributes.ParentObject = device;
        status = WdfSpinLockCreate(&attributes, &ctx->Lock);
        if (!NT_SUCCESS(status))
                return status;

        /* the default queue - parallel dispatch */
        WDF_IO_QUEUE_CONFIG_INIT_DEFAULT_QUEUE(&queueConfig,
                        WdfIoQueueDispatchParallel);
        queueConfig.EvtIoRead          = RbEvtIoRead;
        queueConfig.EvtIoWrite         = RbEvtIoWrite;
        queueConfig.EvtIoDeviceControl = RbEvtIoDeviceControl;

        status = WdfIoQueueCreate(device, &queueConfig,
                        WDF_NO_OBJECT_ATTRIBUTES,
                        &ctx->DefaultQueue);
        if (!NT_SUCCESS(status))
                return status;

        /* the manual queue for pending reads. NOT power
           managed, because the timer DPC retrieves from it
           (chapter 16).                                    */
        WDF_IO_QUEUE_CONFIG_INIT(&queueConfig,
                        WdfIoQueueDispatchManual);
        queueConfig.PowerManaged = WdfFalse;

        status = WdfIoQueueCreate(device, &queueConfig,
                        WDF_NO_OBJECT_ATTRIBUTES,
                        &ctx->PendingReadQueue);
        if (!NT_SUCCESS(status))
                return status;

        /* the data generator, standing in for an interrupt */
        WDF_TIMER_CONFIG_INIT_PERIODIC(&timerConfig,
                                       RbEvtTimer,
                                       ctx->TimerPeriodMs);
        WDF_OBJECT_ATTRIBUTES_INIT(&attributes);
        attributes.ParentObject = device;

        status = WdfTimerCreate(&timerConfig, &attributes,
                                &ctx->Timer);
        if (!NT_SUCCESS(status))
                return status;

        /* publish the interface LAST (chapter 18) */
        status = WdfDeviceCreateDeviceInterface(device,
                        &GUID_DEVINTERFACE_RINGBUF, NULL);
        if (!NT_SUCCESS(status))
                return status;

        WdfTimerStart(ctx->Timer,
                      WDF_REL_TIMEOUT_IN_MS(ctx->TimerPeriodMs));

        KdPrint(("ringbuf: ready, %lu bytes\n", ctx->Capacity));
        return STATUS_SUCCESS;
}

VOID
RbEvtDeviceCleanup(_In_ WDFOBJECT Object)
{
        PRB_CONTEXT ctx = RbGetContext(Object);

        /* stop the timer AND WAIT (chapter 11) - otherwise it
           can fire against the buffer we are about to free */
        if (ctx->Timer)
                WdfTimerStop(ctx->Timer, TRUE);

        if (ctx->Buffer) {
                ExFreePoolWithTag(ctx->Buffer, RB_POOL_TAG);
                ctx->Buffer = NULL;
        }

        /* every WDF object is parented to the device and dies
           with it - no other cleanup needed (chapter 14)   */
}

ring.c

The ring buffer itself, deliberately kept free of any framework code. Isolating the pure logic like this is what makes it testable and what makes the locking easy to reason about.

#include "driver.h"

/* Free-running Head and Tail; unsigned wraparound removes the
   full-versus-empty ambiguity entirely. Same trick as the
   Linux version (chapter 36).                             */

ULONG RbUsed(_In_ PRB_CONTEXT Ctx)
{
        return Ctx->Head - Ctx->Tail;
}

ULONG RbSpace(_In_ PRB_CONTEXT Ctx)
{
        return Ctx->Capacity - RbUsed(Ctx);
}

ULONG
RbPush(_In_ PRB_CONTEXT Ctx,
       _In_reads_bytes_(Len) const UCHAR *Src, _In_ ULONG Len)
{
        ULONG n, first, mask = Ctx->Capacity - 1;

        if (Ctx->Overwrite) {
                if (Len > Ctx->Capacity) {
                        Src += Len - Ctx->Capacity;
                        Ctx->Drops += Len - Ctx->Capacity;
                        Len = Ctx->Capacity;
                }
                if (Len > RbSpace(Ctx)) {
                        ULONG discard = Len - RbSpace(Ctx);

                        Ctx->Tail  += discard;
                        Ctx->Drops += discard;
                }
                n = Len;
        } else {
                n = min(Len, RbSpace(Ctx));
        }

        first = min(n, Ctx->Capacity - (Ctx->Head & mask));
        RtlCopyMemory(Ctx->Buffer + (Ctx->Head & mask),
                      Src, first);
        if (n > first)
                RtlCopyMemory(Ctx->Buffer, Src + first,
                              n - first);

        Ctx->Head         += n;
        Ctx->BytesWritten += n;
        return n;
}

ULONG
RbPop(_In_ PRB_CONTEXT Ctx,
      _Out_writes_bytes_(Len) UCHAR *Dst, _In_ ULONG Len)
{
        ULONG n, first, mask = Ctx->Capacity - 1;

        n = min(Len, RbUsed(Ctx));

        first = min(n, Ctx->Capacity - (Ctx->Tail & mask));
        RtlCopyMemory(Dst, Ctx->Buffer + (Ctx->Tail & mask),
                      first);
        if (n > first)
                RtlCopyMemory(Dst + first, Ctx->Buffer,
                              n - first);

        Ctx->Tail      += n;
        Ctx->BytesRead += n;
        return n;
}

/* Called from the timer DPC and from write, WITHOUT the lock
   held - it takes the lock itself around each pop.        */
VOID
RbCompletePendingReads(_In_ PRB_CONTEXT Ctx)
{
        WDFREQUEST request;
        NTSTATUS status;

        for (;;) {
                PVOID buffer;
                size_t bufLen;
                ULONG got;

                status = WdfIoQueueRetrieveNextRequest(
                                Ctx->PendingReadQueue,
                                &request);
                if (!NT_SUCCESS(status))
                        break;      /* nobody waiting */

                /* WE NOW OWN THIS REQUEST. It cannot be
                   cancelled behind us (chapter 16) - so it
                   MUST be completed on every path below.  */

                status = WdfRequestRetrieveOutputBuffer(request,
                                1, &buffer, &bufLen);
                if (!NT_SUCCESS(status)) {
                        WdfRequestComplete(request, status);
                        continue;
                }

                WdfSpinLockAcquire(Ctx->Lock);
                got = RbPop(Ctx, (PUCHAR)buffer,
                            (ULONG)min(bufLen, MAXULONG));
                if (got)
                        Ctx->PendingReads--;
                WdfSpinLockRelease(Ctx->Lock);

                if (got == 0) {
                        /* raced - nothing left. Put it back
                           rather than completing it with
                           zero, which userspace would read as
                           end of file (chapter 21 of the
                           Linux track).                    */
                        status = WdfRequestForwardToIoQueue(
                                request, Ctx->PendingReadQueue);
                        if (!NT_SUCCESS(status))
                                WdfRequestComplete(request,
                                                   status);
                        break;
                }

                WdfRequestCompleteWithInformation(request,
                                STATUS_SUCCESS, got);
        }
}

queue.c

Where requests actually arrive. This is chapter 16's queues and chapter 17's IOCTLs in their final form, including the cancellation handling that the bench test will never exercise on its own.

#include "driver.h"

VOID
RbEvtIoRead(_In_ WDFQUEUE Queue, _In_ WDFREQUEST Request,
            _In_ size_t Length)
{
        PRB_CONTEXT ctx = RbGetContext(
                        WdfIoQueueGetDevice(Queue));
        PVOID buffer;
        size_t bufLen;
        ULONG got;
        NTSTATUS status;

        if (Length == 0) {
                WdfRequestComplete(Request, STATUS_SUCCESS);
                return;
        }

        status = WdfRequestRetrieveOutputBuffer(Request, 1,
                                                &buffer, &bufLen);
        if (!NT_SUCCESS(status)) {
                WdfRequestComplete(Request, status);
                return;
        }

        WdfSpinLockAcquire(ctx->Lock);
        got = RbPop(ctx, (PUCHAR)buffer,
                    (ULONG)min(bufLen, MAXULONG));
        if (got == 0)
                ctx->PendingReads++;
        WdfSpinLockRelease(ctx->Lock);

        if (got) {
                WdfRequestCompleteWithInformation(Request,
                                STATUS_SUCCESS, got);
                return;
        }

        /* nothing available - park it. The framework now owns
           cancellation and cleanup for this request.      */
        status = WdfRequestForwardToIoQueue(Request,
                                ctx->PendingReadQueue);
        if (!NT_SUCCESS(status)) {
                WdfSpinLockAcquire(ctx->Lock);
                ctx->PendingReads--;
                WdfSpinLockRelease(ctx->Lock);
                WdfRequestComplete(Request, status);
        }
}

VOID
RbEvtIoWrite(_In_ WDFQUEUE Queue, _In_ WDFREQUEST Request,
             _In_ size_t Length)
{
        PRB_CONTEXT ctx = RbGetContext(
                        WdfIoQueueGetDevice(Queue));
        PVOID buffer;
        size_t bufLen;
        ULONG pushed;
        NTSTATUS status;

        if (Length == 0) {
                WdfRequestComplete(Request, STATUS_SUCCESS);
                return;
        }

        status = WdfRequestRetrieveInputBuffer(Request, 1,
                                               &buffer, &bufLen);
        if (!NT_SUCCESS(status)) {
                WdfRequestComplete(Request, status);
                return;
        }

        WdfSpinLockAcquire(ctx->Lock);
        pushed = RbPush(ctx, (const UCHAR *)buffer,
                        (ULONG)min(bufLen, MAXULONG));
        WdfSpinLockRelease(ctx->Lock);

        /* wake anyone waiting - OUTSIDE the lock, because
           completing a request can be slow                */
        if (pushed)
                RbCompletePendingReads(ctx);

        WdfRequestCompleteWithInformation(Request,
                        STATUS_SUCCESS, pushed);
}

VOID
RbEvtTimer(_In_ WDFTIMER Timer)
{
        PRB_CONTEXT ctx = RbGetContext(
                        WdfTimerGetParentObject(Timer));
        UCHAR sample[16];
        ULONG i;

        /* DISPATCH_LEVEL. No paged memory, no blocking
           (chapter 03).                                    */

        WdfSpinLockAcquire(ctx->Lock);
        ctx->TimerTicks++;
        for (i = 0; i < sizeof(sample); i++)
                sample[i] = (UCHAR)(ctx->TimerTicks + i);
        RbPush(ctx, sample, sizeof(sample));
        WdfSpinLockRelease(ctx->Lock);

        RbCompletePendingReads(ctx);
}

VOID
RbEvtIoDeviceControl(_In_ WDFQUEUE Queue,
                     _In_ WDFREQUEST Request,
                     _In_ size_t OutputBufferLength,
                     _In_ size_t InputBufferLength,
                     _In_ ULONG IoControlCode)
{
        PRB_CONTEXT ctx = RbGetContext(
                        WdfIoQueueGetDevice(Queue));
        NTSTATUS status = STATUS_INVALID_DEVICE_REQUEST;
        size_t info = 0;

        UNREFERENCED_PARAMETER(OutputBufferLength);
        UNREFERENCED_PARAMETER(InputBufferLength);

        switch (IoControlCode) {

        case IOCTL_RB_GET_STATS: {
                PRB_STATS st;

                status = WdfRequestRetrieveOutputBuffer(Request,
                                sizeof(RB_STATS),
                                (PVOID *)&st, NULL);
                if (!NT_SUCCESS(status))
                        break;

                RtlZeroMemory(st, sizeof(*st));

                WdfSpinLockAcquire(ctx->Lock);
                st->Capacity     = ctx->Capacity;
                st->Used         = RbUsed(ctx);
                st->BytesWritten = ctx->BytesWritten;
                st->BytesRead    = ctx->BytesRead;
                st->Drops        = ctx->Drops;
                st->TimerTicks   = ctx->TimerTicks;
                st->PendingReads = ctx->PendingReads;
                WdfSpinLockRelease(ctx->Lock);

                info = sizeof(RB_STATS);
                status = STATUS_SUCCESS;
                break;
        }

        case IOCTL_RB_RESET:
                WdfSpinLockAcquire(ctx->Lock);
                ctx->Head = ctx->Tail = 0;
                WdfSpinLockRelease(ctx->Lock);
                status = STATUS_SUCCESS;
                break;

        case IOCTL_RB_SET_CONFIG: {
                PRB_CONFIG cfg;
                RB_CONFIG local;

                status = WdfRequestRetrieveInputBuffer(Request,
                                sizeof(RB_CONFIG),
                                (PVOID *)&cfg, NULL);
                if (!NT_SUCCESS(status))
                        break;

                /* COPY IN, then validate the copy
                   (chapter 17)                             */
                RtlCopyMemory(&local, cfg, sizeof(local));

                if (local.Overwrite > 1) {
                        status = STATUS_INVALID_PARAMETER;
                        break;
                }
                if (local.TimerPeriodMs > 10000) {
                        status = STATUS_INVALID_PARAMETER;
                        break;
                }

                WdfSpinLockAcquire(ctx->Lock);
                ctx->Overwrite     = (BOOLEAN)local.Overwrite;
                ctx->TimerPeriodMs = local.TimerPeriodMs;
                WdfSpinLockRelease(ctx->Lock);

                WdfTimerStop(ctx->Timer, FALSE);
                if (local.TimerPeriodMs)
                        WdfTimerStart(ctx->Timer,
                                WDF_REL_TIMEOUT_IN_MS(
                                        local.TimerPeriodMs));

                status = STATUS_SUCCESS;
                break;
        }

        case IOCTL_RB_GET_CONFIG: {
                PRB_CONFIG cfg;

                status = WdfRequestRetrieveOutputBuffer(Request,
                                sizeof(RB_CONFIG),
                                (PVOID *)&cfg, NULL);
                if (!NT_SUCCESS(status))
                        break;

                RtlZeroMemory(cfg, sizeof(*cfg));
                cfg->Overwrite     = ctx->Overwrite;
                cfg->TimerPeriodMs = ctx->TimerPeriodMs;
                info = sizeof(RB_CONFIG);
                status = STATUS_SUCCESS;
                break;
        }

        default:
                break;
        }

        WdfRequestCompleteWithInformation(Request, status, info);
}

Building and installing

With everything written, this is the loop you will repeat dozens of times: build, deploy to the test machine, install, exercise, read the trace. Making it fast is worth the setup effort.

# --- On the DEVELOPMENT machine ---
    msbuild ringbuf.vcxproj /p:Configuration=Debug \
            /p:Platform=x64
    ; the WDK template signs it with a test certificate

# --- On the TEST machine (a VM), once ---
    bcdedit /set testsigning on
    bcdedit /debug on
    bcdedit /dbgsettings serial debugport:1 baudrate:115200
    shutdown /r /t 0

# --- Install ---
    certmgr /add ringbuf.cer /s /r localMachine root
    certmgr /add ringbuf.cer /s /r localMachine trustedpublisher

    pnputil /add-driver ringbuf.inf /install
    devcon install ringbuf.inf root\ringbuf

# --- Verify it started ---
    devcon status root\ringbuf
      root\ringbuf\0000
          Name: RingBuf Test Device
          Driver is running.

    ; and in Device Manager, under System devices

# --- The development loop, scripted ---
    devcon remove root\ringbuf
    pnputil /delete-driver oem12.inf /uninstall /force
    ; rebuild, copy over
    pnputil /add-driver ringbuf.inf /install
    devcon install ringbuf.inf root\ringbuf

# --- Turn the verifiers on immediately (chapter 22) ---
    verifier /flags 0x209BB /driver ringbuf.sys
    shutdown /r /t 0

Exercises

Break it deliberately. Each of these produces a specific, diagnosable failure.
  1. Remove the spinlock from RbEvtIoWrite. Run several writers and a reader. Watch the counters drift. Then re-add it.
  2. Allocate the buffer from paged pool. Enable Verifier's force-IRQL flag. The timer DPC now bugchecks with 0xA immediately, rather than in three weeks (chapter 03).
  3. Complete a forwarded request. In RbEvtIoRead, call WdfRequestComplete after WdfRequestForwardToIoQueue. WDF Verifier catches it (chapter 14).
  4. Make the pending queue power-managed. Let the device idle, then read. The request never completes — and !wdfdevicequeues shows the queue not dispatching (chapter 16).
  5. Drop WdfTimerStop(..., TRUE) from cleanup. Uninstall while the timer is running. With special pool on, you get a use-after-free bugcheck naming your driver.
  6. Skip the RtlZeroMemory in GET_STATS. The reserved fields now leak whatever was in the buffer — an information disclosure, in one deleted line.
  7. Remove the validation from SET_CONFIG and pass a huge TimerPeriodMs. Then run the WDK's IoAttack fuzzer against it and see what else it finds.
  8. Change IOCTL_RB_RESET to FILE_ANY_ACCESS and reset the buffer from a read-only handle. Observe that the platform was preventing this for free (chapter 17).
  9. Leak pool: remove the ExFreePoolWithTag. Install and uninstall ten times with pool tracking on. Bugcheck 0xC4, Arg1 = 0x62, with the allocation stack.
  10. Add a feature: support several concurrent readers, each with an independent read position. This requires per-file-object state (chapter 16) and changes the ring's semantics — think carefully about what "consumed" means with several readers.
  11. Add an EvtIoStop handler and verify the machine can now sleep with a read pending.
  12. Convert to a real interrupt. If you have any PCIe device with a documented register map, replace the timer with a WDFINTERRUPT (chapter 18). The queue and completion logic does not change at all — which is the point.

The review pass
