Heaps: top-K, merging and two-heap median

A structure that gives you the smallest (or largest) element instantly and lets you replace it in log time. Whenever a problem says "kth" or "top K" or "median of a stream", this is the answer.

The pattern

A heap is a tree that is actually an array, which is the trick that makes it fast and the reason the index arithmetic looks arbitrary. It is worth seeing the layout before the operations.

   A BINARY HEAP is a complete binary tree stored in a flat
   array, with the HEAP PROPERTY: every parent is <= (min
   heap) or >= (max heap) both of its children.

     index i:   parent  (i-1) >> 1
                left    2i + 1
                right   2i + 2

     min heap        [1, 3, 6, 5, 9, 8]
                          1
                        /   \
                       3     6
                      / \   /
                     5   9 8

   NOTE WHAT IT DOES NOT GIVE YOU: the heap is NOT sorted.
   Only the ROOT is guaranteed to be the extreme. Anything
   asking for full order needs a sort.

   OPERATIONS
     peek        O(1)
     push        O(log n)   — append, then SIFT UP
     pop         O(log n)   — swap root with last, shrink,
                              SIFT DOWN
     heapify     O(n)       — building from an array is
                              LINEAR, not n log n

   ---------------------------------------------------------
   THE TOP-K PATTERN — the one that matters most

     "K LARGEST"  -> keep a MIN heap of size k
     "K SMALLEST" -> keep a MAX heap of size k

   THAT INVERSION SURPRISES PEOPLE. For the k largest, the
   min heap's root is the WEAKEST of your current winners —
   the one to evict when something better arrives:

       for (const x of items) {
           heap.push(x);
           if (heap.size() > k) heap.pop();   // drop the
       }                                      // smallest
       // the heap now holds the k largest; its root is the
       // kth largest

     COST O(n log k), and SPACE O(k) — which beats sorting
     (O(n log n), O(n)) when k is small, and is the only
     option for a STREAM you cannot store.

   ---------------------------------------------------------
   THE TWO-HEAP PATTERN — median of a stream

     MAX heap for the lower half, MIN heap for the upper.
     Keep the sizes within one of each other.

        lower (max heap)     upper (min heap)
          ... 3 4 |            | 5 6 ...
              ^ root             ^ root

     median = root of the bigger heap, or the mean of both
     roots when the sizes are equal.

     Insert: push to one, then move its root to the other to
     restore the ordering, then rebalance the sizes. Always
     push-then-transfer, or an element can end up on the
     wrong side.
JavaScript has no built-in heap

C++ has priority_queue, Java has PriorityQueue, Python has heapq (a min heap — negate values for a max heap). JavaScript has nothing, so you write one. The implementation below is about 25 lines and is worth being able to produce from memory; the problems on this page provide it for you so you can focus on the pattern.

class MinHeap {
    constructor(cmp = (a, b) => a - b) { this.a = []; this.cmp = cmp; }
    size()  { return this.a.length; }
    peek()  { return this.a[0]; }

    push(v) {
        this.a.push(v);
        let i = this.a.length - 1;
        while (i > 0) {                       // SIFT UP
            const p = (i - 1) >> 1;
            if (this.cmp(this.a[i], this.a[p]) >= 0) break;
            [this.a[i], this.a[p]] = [this.a[p], this.a[i]];
            i = p;
        }
    }

    pop() {
        const top = this.a[0];
        const last = this.a.pop();
        if (this.a.length) {
            this.a[0] = last;
            let i = 0;                        // SIFT DOWN
            for (;;) {
                const l = 2*i + 1, r = l + 1;
                let m = i;
                if (l < this.a.length && this.cmp(this.a[l], this.a[m]) < 0) m = l;
                if (r < this.a.length && this.cmp(this.a[r], this.a[m]) < 0) m = r;
                if (m === i) break;
                [this.a[i], this.a[m]] = [this.a[m], this.a[i]];
                i = m;
            }
        }
        return top;
    }
}

/* A MAX HEAP is the same class with a flipped comparator: */
new MinHeap((a, b) => b - a);

When to reach for it

"Kth largest / smallest"

Size-k heap of the opposite polarity. O(n log k).

"Top K frequent"

Count with a map, then a size-k heap — or bucket sort for O(n).

Merge K sorted lists/arrays

Heap of the K current heads.

Median of a data stream

Two heaps, balanced.

Scheduling / "next event"

Task scheduler, meeting rooms, Dijkstra (ch. 34).

K closest points

Max heap of size k keyed on distance — no need to sort everything.
