Project: the trusted application, and running it on QEMU

The secure half of the project: an OP-TEE trusted application written in C++, a bridge daemon that connects it to the Windows guest, and the two-VM QEMU topology that lets you run the whole thing on a laptop. Plus an honest accounting of which security properties this configuration demonstrates and which it only simulates.

The topology

This project has more moving parts than any other in the track, so start with the map: which component runs where, and which boundary each message crosses. Everything afterwards is easier with that picture fixed.

   ONE HOST MACHINE, THREE PROCESSES

   +--------------------------+     +---------------------------+
   |  QEMU instance A         |     |  QEMU instance B          |
   |                          |     |                           |
   |  Windows 11 ARM64        |     |  TF-A + OP-TEE + Linux    |
   |    secteectl.exe         |     |    secteed  (bridge, C++) |
   |    sectee.sys            |     |      |  libteec           |
   |      |                   |     |      v                    |
   |      | ivshmem PCI       |     |    /dev/tee0              |
   +------|-------------------+     +------|--------------------+
          |                                |   SMC
          |                                v
          |                         +---------------------+
          |                         |  sectee_ta  S-EL0   |
          |                         |  C++, RAII          |
          |                         +---------------------+
          |                                |
          +--------------+-----------------+
                         |
              +----------v-----------+
              |  ivshmem-server      |   stock QEMU utility.
              |  (host process)      |   Hands both VMs the same
              |  shared memory file  |   memory and relays
              +----------------------+   doorbell interrupts.

   Windows is a guest. OP-TEE is in a DIFFERENT guest. They meet
   in a page of shared memory that the host mediates.

   Nothing here is patched. ivshmem, ivshmem-server, the OP-TEE
   QEMU manifest and Windows ARM64 are all stock.
What this configuration does and does not prove

Does: that the driver, the ABI, the marshalling, the trusted application and the client are all correct; that a key generated inside OP-TEE signs digests the Windows guest computes; that CNG in the Windows kernel accepts those signatures. Every line of software is exercised for real.

Does not: demonstrate TrustZone isolation. The Windows guest is separated from the TA by VM boundaries, not by the NS bit. On production hardware the same driver reaches the same TA through TrEE and the isolation is real; here it is a development harness. Never quote a QEMU run as evidence of a security property.

Why write a TA in C++

Not for templates or the STL — neither is available. For one thing only, and it is worth the whole chapter: destructors. Compare the C key-store TA of OP-TEE chapter 21 with what follows.

   THE C SHAPE, from chapter 22          THE C++ SHAPE

   TEE_ObjectHandle  obj = NULL;         {
   TEE_OperationHandle op = NULL;            PersistentKey key(id);
   res = open(&obj);                         if (!key) return key.Error();
   if (res) goto out;
   res = TEE_AllocateOperation(&op...);      SignOperation op(key);
   if (res) goto out;                        if (!op) return op.Error();
   res = TEE_SetOperationKey(op, obj);
   if (res) goto out;                        return op.Sign(digest, sig);
   res = TEE_AsymmetricSignDigest(...);  }   // both freed here, on
   out:                                      // EVERY path, in reverse
       TEE_FreeOperation(op);                // order, including the
       TEE_CloseObject(obj);                 // early returns
       return res;

   A leaked TEE_OperationHandle is not a tidiness problem. The
   secure heap is a few tens of kilobytes (chapter 07); leak one
   per request and the TA panics after a few thousand
   operations, in production, weeks later, under load.

   The goto ladder works. It also breaks the moment someone adds
   a fourth resource in the middle and forgets one branch. RAII
   makes that class of bug unrepresentable.

The trusted application

The trusted application is the code that runs inside the secure world, where the private key lives. It is an ordinary program with an unusual set of restrictions, and it never lets the key leave.

constexpr const char KEY_ID[]     = "sectee.key.v1";
constexpr const char COUNTER_ID[] = "sectee.counter.v1";
constexpr uint32_t   P256_BITS    = 256;

// ---------------------------------------------------------------
// RAII wrappers. Each owns exactly one TEE handle, is
// non-copyable, and frees on destruction. This is the entire
// argument for C++ here.
// ---------------------------------------------------------------

class Operation
{
public:
    Operation(uint32_t alg, uint32_t mode, uint32_t maxKeyBits)
    {
        m_res = TEE_AllocateOperation(&m_h, alg, mode, maxKeyBits);
        if (m_res != TEE_SUCCESS) m_h = TEE_HANDLE_NULL;
    }
    ~Operation()
    {
        if (m_h != TEE_HANDLE_NULL) TEE_FreeOperation(m_h);
    }

    Operation(const Operation&)            = delete;
    Operation& operator=(const Operation&) = delete;

    explicit operator bool() const { return m_res == TEE_SUCCESS; }
    TEE_Result Error() const       { return m_res; }
    TEE_OperationHandle Get() const { return m_h; }

private:
    TEE_OperationHandle m_h   = TEE_HANDLE_NULL;
    TEE_Result          m_res = TEE_SUCCESS;
};

class TransientObject
{
public:
    TransientObject(uint32_t type, uint32_t maxKeyBits)
    {
        m_res = TEE_AllocateTransientObject(type, maxKeyBits, &m_h);
        if (m_res != TEE_SUCCESS) m_h = TEE_HANDLE_NULL;
    }
    ~TransientObject()
    {
        if (m_h != TEE_HANDLE_NULL) TEE_FreeTransientObject(m_h);
    }

    TransientObject(const TransientObject&)            = delete;
    TransientObject& operator=(const TransientObject&) = delete;

    explicit operator bool() const { return m_res == TEE_SUCCESS; }
    TEE_Result Error() const        { return m_res; }
    TEE_ObjectHandle Get() const    { return m_h; }
    TEE_ObjectHandle* Put()         { return &m_h; }

private:
    TEE_ObjectHandle m_h   = TEE_HANDLE_NULL;
    TEE_Result       m_res = TEE_SUCCESS;
};

class PersistentObject
{
public:
    PersistentObject() = default;

    ~PersistentObject()
    {
        if (m_h != TEE_HANDLE_NULL) TEE_CloseObject(m_h);
    }

    PersistentObject(const PersistentObject&)            = delete;
    PersistentObject& operator=(const PersistentObject&) = delete;

    TEE_Result Open(const char* id, size_t idLen, uint32_t flags)
    {
        return TEE_OpenPersistentObject(TEE_STORAGE_PRIVATE,
                                        id, idLen, flags, &m_h);
    }

    TEE_Result Create(const char* id, size_t idLen, uint32_t flags,
                      TEE_ObjectHandle attrs,
                      const void* initial, size_t initialLen)
    {
        return TEE_CreatePersistentObject(TEE_STORAGE_PRIVATE,
                                          id, idLen, flags, attrs,
                                          initial, initialLen, &m_h);
    }

    // Release ownership without closing - used when we hand the
    // handle to TEE_CloseAndDeletePersistentObject1, which closes
    // it for us. Double-closing a TEE handle panics the TA.
    TEE_ObjectHandle Release()
    {
        TEE_ObjectHandle h = m_h;
        m_h = TEE_HANDLE_NULL;
        return h;
    }

    bool Valid() const           { return m_h != TEE_HANDLE_NULL; }
    TEE_ObjectHandle Get() const { return m_h; }

private:
    TEE_ObjectHandle m_h = TEE_HANDLE_NULL;
};

// Open the signing key, generating it on first use.
//
// The private scalar is created by TEE_GenerateKey inside S-EL0 and
// written into a persistent object that OP-TEE encrypts with a key
// derived from the hardware unique key (OP-TEE chapter 15). It is
// never serialised into a buffer, so it never exists anywhere the
// normal world could observe even in principle.
TEE_Result OpenOrCreateKey(PersistentObject& out)
{
    TEE_Result res = out.Open(KEY_ID, sizeof(KEY_ID) - 1,
                              TEE_DATA_FLAG_ACCESS_READ);
    if (res == TEE_SUCCESS) return TEE_SUCCESS;
    if (res != TEE_ERROR_ITEM_NOT_FOUND) return res;

    IMSG("generating a new P-256 keypair");

    TransientObject key(TEE_TYPE_ECDSA_KEYPAIR, P256_BITS);
    if (!key) return key.Error();

    TEE_Attribute curve;
    TEE_InitValueAttribute(&curve, TEE_ATTR_ECC_CURVE,
                           TEE_ECC_CURVE_NIST_P256, 0);

    res = TEE_GenerateKey(key.Get(), P256_BITS, &curve, 1);
    if (res != TEE_SUCCESS) return res;

    // Persist the OBJECT, not bytes.
    return out.Create(KEY_ID, sizeof(KEY_ID) - 1,
                      TEE_DATA_FLAG_ACCESS_READ |
                      TEE_DATA_FLAG_ACCESS_WRITE_META,
                      key.Get(), nullptr, 0);
    // `key` is freed here by its destructor, on every path above.
}

// Copy an ECC coordinate out, LEFT-PADDED to a fixed 32 bytes.
//
// TEE_GetObjectBufferAttribute returns the minimal encoding, so a
// coordinate with a leading zero byte comes back 31 bytes long -
// about one time in 256. Writing it flush-left produces a key that
// works 99.6% of the time, which is the worst possible failure
// rate: too rare to catch in testing, common enough to ship.
TEE_Result GetCoordinate(TEE_ObjectHandle obj, uint32_t attrId,
                         uint8_t out[32])
{
    uint8_t  tmp[32];
    uint32_t len = sizeof(tmp);

    TEE_Result res = TEE_GetObjectBufferAttribute(obj, attrId,
                                                  tmp, &len);
    if (res != TEE_SUCCESS) return res;
    if (len > 32) return TEE_ERROR_BAD_STATE;

    TEE_MemFill(out, 0, 32);
    TEE_MemMove(out + (32 - len), tmp, len);
    return TEE_SUCCESS;
}

// ---------------------------------------------------------------
// TA_CMD_GET_PUBKEY   [0] memref out, 64 bytes
// ---------------------------------------------------------------
TEE_Result CmdGetPubkey(uint32_t ptypes, TEE_Param params[4])
{
    const uint32_t expected =
        TEE_PARAM_TYPES(TEE_PARAM_TYPE_MEMREF_OUTPUT,
                        TEE_PARAM_TYPE_NONE,
                        TEE_PARAM_TYPE_NONE,
                        TEE_PARAM_TYPE_NONE);
    if (ptypes != expected)
    {
        EMSG("ptypes 0x%08x expected 0x%08x", ptypes, expected);
        return TEE_ERROR_BAD_PARAMETERS;
    }
    if (params[0].memref.size < SECTEE_PUBKEY_LEN)
    {
        params[0].memref.size = SECTEE_PUBKEY_LEN;
        return TEE_ERROR_SHORT_BUFFER;
    }

    PersistentObject key;
    TEE_Result res = OpenOrCreateKey(key);
    if (res != TEE_SUCCESS) return res;

    uint8_t pub[SECTEE_PUBKEY_LEN];
    res = GetCoordinate(key.Get(), TEE_ATTR_ECC_PUBLIC_VALUE_X, pub);
    if (res != TEE_SUCCESS) return res;
    res = GetCoordinate(key.Get(), TEE_ATTR_ECC_PUBLIC_VALUE_Y, pub + 32);
    if (res != TEE_SUCCESS) return res;

    // Write the output ONCE, at the end, on success only.
    TEE_MemMove(params[0].memref.buffer, pub, SECTEE_PUBKEY_LEN);
    params[0].memref.size = SECTEE_PUBKEY_LEN;
    return TEE_SUCCESS;
}

// ---------------------------------------------------------------
// TA_CMD_SIGN   [0] memref in  (32-byte digest)
//               [1] memref out (64-byte signature)
// ---------------------------------------------------------------
TEE_Result CmdSign(uint32_t ptypes, TEE_Param params[4])
{
    const uint32_t expected =
        TEE_PARAM_TYPES(TEE_PARAM_TYPE_MEMREF_INPUT,
                        TEE_PARAM_TYPE_MEMREF_OUTPUT,
                        TEE_PARAM_TYPE_NONE,
                        TEE_PARAM_TYPE_NONE);
    if (ptypes != expected) return TEE_ERROR_BAD_PARAMETERS;

    // Exactly 32 bytes or nothing. A fixed size means there is no
    // length arithmetic in this function to get wrong.
    if (params[0].memref.size != SECTEE_DIGEST_LEN)
        return TEE_ERROR_BAD_PARAMETERS;
    if (params[1].memref.size < SECTEE_SIG_LEN)
    {
        params[1].memref.size = SECTEE_SIG_LEN;
        return TEE_ERROR_SHORT_BUFFER;
    }

    if (TEE_CheckMemoryAccessRights(
            TEE_MEMORY_ACCESS_READ | TEE_MEMORY_ACCESS_ANY_OWNER,
            params[0].memref.buffer,
            SECTEE_DIGEST_LEN) != TEE_SUCCESS)
        return TEE_ERROR_ACCESS_DENIED;

    // ONE fetch out of shared memory, then work on the copy. The
    // normal world can rewrite that buffer at any instant,
    // including between two reads of the same byte
    // (OP-TEE chapter 20).
    uint8_t digest[SECTEE_DIGEST_LEN];
    TEE_MemMove(digest, params[0].memref.buffer, SECTEE_DIGEST_LEN);

    PersistentObject key;
    TEE_Result res = OpenOrCreateKey(key);
    if (res != TEE_SUCCESS) return res;

    Operation op(TEE_ALG_ECDSA_P256, TEE_MODE_SIGN, P256_BITS);
    if (!op) return op.Error();

    res = TEE_SetOperationKey(op.Get(), key.Get());
    if (res != TEE_SUCCESS) return res;

    uint8_t  sig[SECTEE_SIG_LEN];
    uint32_t sigLen = sizeof(sig);

    res = TEE_AsymmetricSignDigest(op.Get(), nullptr, 0,
                                   digest, SECTEE_DIGEST_LEN,
                                   sig, &sigLen);
    if (res != TEE_SUCCESS) return res;

    TEE_MemMove(params[1].memref.buffer, sig, sigLen);
    params[1].memref.size = sigLen;

    TEE_MemFill(digest, 0, sizeof(digest));
    return TEE_SUCCESS;
    // op and key are released here, in reverse order, on this path
    // and on all eight early returns above.
}

// ---------------------------------------------------------------
// TA_CMD_COUNTER   [0] value inout: a = increment?, b unused
//                                   out: a = low32, b = high32
// ---------------------------------------------------------------
TEE_Result CmdCounter(uint32_t ptypes, TEE_Param params[4])
{
    const uint32_t expected =
        TEE_PARAM_TYPES(TEE_PARAM_TYPE_VALUE_INOUT,
                        TEE_PARAM_TYPE_NONE,
                        TEE_PARAM_TYPE_NONE,
                        TEE_PARAM_TYPE_NONE);
    if (ptypes != expected) return TEE_ERROR_BAD_PARAMETERS;

    const bool increment = (params[0].value.a == 1);
    uint64_t   value     = 0;

    PersistentObject obj;
    TEE_Result res = obj.Open(COUNTER_ID, sizeof(COUNTER_ID) - 1,
                              TEE_DATA_FLAG_ACCESS_READ |
                              TEE_DATA_FLAG_ACCESS_WRITE);

    if (res == TEE_SUCCESS)
    {
        uint32_t got = 0;
        res = TEE_ReadObjectData(obj.Get(), &value, sizeof(value), &got);
        if (res != TEE_SUCCESS) return res;
        if (got != sizeof(value)) value = 0;

        if (increment)
        {
            value++;
            res = TEE_SeekObjectData(obj.Get(), 0, TEE_DATA_SEEK_SET);
            if (res != TEE_SUCCESS) return res;
            res = TEE_WriteObjectData(obj.Get(), &value, sizeof(value));
            if (res != TEE_SUCCESS) return res;
        }
    }
    else if (res == TEE_ERROR_ITEM_NOT_FOUND)
    {
        value = increment ? 1 : 0;
        res = obj.Create(COUNTER_ID, sizeof(COUNTER_ID) - 1,
                         TEE_DATA_FLAG_ACCESS_READ |
                         TEE_DATA_FLAG_ACCESS_WRITE |
                         TEE_DATA_FLAG_ACCESS_WRITE_META,
                         TEE_HANDLE_NULL, &value, sizeof(value));
        if (res != TEE_SUCCESS) return res;
    }
    else
    {
        return res;
    }

    // A GP value parameter is a pair of u32, so a u64 goes across
    // in two halves (OP-TEE chapter 12).
    params[0].value.a = static_cast<uint32_t>(value & 0xffffffffu);
    params[0].value.b = static_cast<uint32_t>(value >> 32);
    return TEE_SUCCESS;
}

} // anonymous namespace

                                      uint32_t ptypes,

    (void)sessCtx;
    switch (cmd)
    {

    case TA_CMD_SIGN:       return CmdSign(ptypes, params);
    case TA_CMD_COUNTER:    return CmdCounter(ptypes, params);
    default:                return TEE_ERROR_NOT_SUPPORTED;
    }
}

Three C++ traps specific to a TA

Globals with constructors. There is no CRT to run them. Anything at file scope must be constexpr or a POD, which is why the constants above are constexpr and every stateful object is a local. Function-local statics. They emit __cxa_guard_acquire unless you pass -fno-threadsafe-statics. Double-free. TEE_CloseAndDeletePersistentObject1 closes the handle itself, so an RAII wrapper must Release() first — closing a TEE handle twice panics the TA, and the panic appears on the secure console with a stack you will have to decode by hand (OP-TEE chapter 19).

The bridge daemon

Something has to carry requests from the Windows side to the secure world, because the two do not share a transport. The bridge is that component, and it is deliberately thin — it moves bytes and makes no decisions.

namespace {

constexpr uint32_t MAILBOX_MAGIC    = 0x4D454554u;  // "TEEM"
constexpr uint32_t MAILBOX_VERSION  = 1u;
constexpr size_t   MAILBOX_DATA_OFF = 0x100;

// Byte-for-byte the layout the Windows driver declares. If these
// two structs ever disagree the symptom is silent nonsense, so
// keep them in one place if you can and assert the size if you
// cannot.
#pragma pack(push, 8)
struct MailboxHeader
{
    uint32_t Magic;
    uint32_t Version;
    volatile int32_t Sequence;   // written by Windows
    volatile int32_t Ack;        // written by us
    uint32_t Command;
    uint32_t InLength;
    uint32_t OutLength;
    int32_t  Result;
};
#pragma pack(pop)
static_assert(sizeof(MailboxHeader) == 32, "layout drift");

// RAII again, on this side too.
class TeeSession
{
public:
    TeeSession()
    {
        TEEC_Result res = TEEC_InitializeContext(nullptr, &m_ctx);
        if (res != TEEC_SUCCESS)
            throw std::runtime_error("TEEC_InitializeContext: " +
                                     std::to_string(res));
        m_haveCtx = true;

        TEEC_UUID uuid = SECTEE_TA_UUID;
        uint32_t origin = 0;
        res = TEEC_OpenSession(&m_ctx, &m_sess, &uuid,
                               TEEC_LOGIN_PUBLIC, nullptr,
                               nullptr, &origin);
        if (res != TEEC_SUCCESS)
            throw std::runtime_error("TEEC_OpenSession: " +
                                     std::to_string(res) +
                                     " origin " + std::to_string(origin));
        m_haveSess = true;
    }

    ~TeeSession()
    {
        if (m_haveSess) TEEC_CloseSession(&m_sess);
        if (m_haveCtx)  TEEC_FinalizeContext(&m_ctx);
    }

    TeeSession(const TeeSession&)            = delete;
    TeeSession& operator=(const TeeSession&) = delete;

    // Returns the TEE_Result; fills out/outLen on success.
    uint32_t Invoke(uint32_t cmd,
                    const uint8_t* in, uint32_t inLen,
                    uint8_t* out, uint32_t* outLen)
    {
        TEEC_Operation op{};
        uint32_t origin = 0;

        switch (cmd)
        {
        case TA_CMD_GET_PUBKEY:
            op.paramTypes = TEEC_PARAM_TYPES(TEEC_MEMREF_TEMP_OUTPUT,
                                             TEEC_NONE, TEEC_NONE,
                                             TEEC_NONE);
            op.params[0].tmpref.buffer = out;
            op.params[0].tmpref.size   = *outLen;
            break;

        case TA_CMD_SIGN:
            if (inLen != SECTEE_DIGEST_LEN) return TEEC_ERROR_BAD_PARAMETERS;
            op.paramTypes = TEEC_PARAM_TYPES(TEEC_MEMREF_TEMP_INPUT,
                                             TEEC_MEMREF_TEMP_OUTPUT,
                                             TEEC_NONE, TEEC_NONE);
            op.params[0].tmpref.buffer = const_cast<uint8_t*>(in);
            op.params[0].tmpref.size   = inLen;
            op.params[1].tmpref.buffer = out;
            op.params[1].tmpref.size   = *outLen;
            break;

        case TA_CMD_COUNTER:
        {
            if (inLen != sizeof(uint32_t)) return TEEC_ERROR_BAD_PARAMETERS;
            uint32_t increment;
            std::memcpy(&increment, in, sizeof(increment));

            op.paramTypes = TEEC_PARAM_TYPES(TEEC_VALUE_INOUT,
                                             TEEC_NONE, TEEC_NONE,
                                             TEEC_NONE);
            op.params[0].value.a = increment;
            op.params[0].value.b = 0;

            uint32_t res = TEEC_InvokeCommand(&m_sess, cmd, &op, &origin);
            if (res != TEEC_SUCCESS) return res;

            uint64_t value = static_cast<uint64_t>(op.params[0].value.a) |
                             (static_cast<uint64_t>(op.params[0].value.b) << 32);
            if (*outLen < sizeof(value)) return TEEC_ERROR_SHORT_BUFFER;
            std::memcpy(out, &value, sizeof(value));
            *outLen = sizeof(value);
            return TEEC_SUCCESS;
        }

        default:
            return TEEC_ERROR_NOT_SUPPORTED;
        }

        uint32_t res = TEEC_InvokeCommand(&m_sess, cmd, &op, &origin);
        if (res != TEEC_SUCCESS)
        {
            std::fprintf(stderr, "cmd %u -> 0x%08x origin %u\n",
                         cmd, res, origin);
            return res;
        }

        *outLen = (cmd == TA_CMD_GET_PUBKEY)
                ? op.params[0].tmpref.size
                : op.params[1].tmpref.size;
        return TEEC_SUCCESS;
    }

private:
    TEEC_Context m_ctx{};
    TEEC_Session m_sess{};
    bool m_haveCtx  = false;
    bool m_haveSess = false;
};

} // namespace

int main(int argc, char** argv)
{
    const char* uio = (argc > 1) ? argv[1] : "/dev/uio0";

    try
    {
        // ivshmem in the Linux guest shows up as a uio device.
        // map1 is BAR2, the shared memory.
        int fd = open(uio, O_RDWR);
        if (fd < 0) throw std::runtime_error(std::string("open ") + uio);

        // Size comes from sysfs; 1 MB is what we ask ivshmem-server for.
        constexpr size_t SHM_SIZE = 1024 * 1024;

        void* shm = mmap(nullptr, SHM_SIZE, PROT_READ | PROT_WRITE,
                         MAP_SHARED, fd, 1 * getpagesize());
        if (shm == MAP_FAILED) throw std::runtime_error("mmap BAR2");

        auto* hdr  = static_cast<MailboxHeader*>(shm);
        auto* data = static_cast<uint8_t*>(shm) + MAILBOX_DATA_OFF;

        TeeSession tee;   // opens the TA, and closes it on any throw

        // Publish the magic LAST, after everything is ready. The
        // Windows driver refuses to start until it sees this, so
        // it doubles as a readiness handshake.
        hdr->Version  = MAILBOX_VERSION;
        hdr->Ack      = hdr->Sequence;
        std::atomic_thread_fence(std::memory_order_release);
        hdr->Magic    = MAILBOX_MAGIC;

        std::printf("secteed: ready, waiting for the Windows guest\n");

        int32_t lastSeq = hdr->Sequence;

        for (;;)
        {
            // Wait for the doorbell. Reading the uio fd blocks
            // until an interrupt arrives; the 32-bit value is the
            // interrupt count.
            uint32_t count = 0;
            struct pollfd pfd { fd, POLLIN, 0 };

            if (poll(&pfd, 1, 1000) > 0)
                (void)!read(fd, &count, sizeof(count));

            const int32_t seq = hdr->Sequence;
            if (seq == lastSeq) continue;      // spurious wake

            // Observe the sequence number before the payload it
            // announces. Mirrors the barrier on the Windows side.
            std::atomic_thread_fence(std::memory_order_acquire);

            const uint32_t cmd   = hdr->Command;
            const uint32_t inLen = hdr->InLength;

            uint32_t outLen = MAILBOX_DATA_MAX;
            uint32_t result = TEEC_ERROR_GENERIC;

            if (inLen <= MAILBOX_DATA_MAX)
            {
                // Copy out of shared memory before use: the peer
                // could rewrite it while we work. Same discipline
                // the TA applies to ITS shared buffer.
                static uint8_t inCopy[MAILBOX_DATA_MAX];
                std::memcpy(inCopy, data, inLen);

                result = tee.Invoke(cmd, inCopy, inLen, data, &outLen);
            }
            else
            {
                outLen = 0;
                result = TEEC_ERROR_BAD_PARAMETERS;
            }

            hdr->OutLength = (result == TEEC_SUCCESS) ? outLen : 0;
            hdr->Result    = static_cast<int32_t>(result);

            // Payload before Ack, always.
            std::atomic_thread_fence(std::memory_order_release);
            hdr->Ack = seq;

            lastSeq = seq;
        }
    }
    catch (const std::exception& e)
    {
        std::fprintf(stderr, "secteed: %s\n", e.what());
        return 1;
    }
}

Proving it independently

A security property you cannot verify from outside is not a property, it is a hope. This is the independent check, using tooling that knows nothing about your implementation.

# Everything above trusted our own code to check our own code.
# Take the artefacts out and verify with stock OpenSSL, which has
# never heard of OP-TEE, ivshmem or Windows.

# In Windows, capture the public key and a signature:
C:\> secteectl.exe pubkey > C:\pub.hex
C:\> secteectl.exe sign C:\msg.txt > C:\sig.txt

# Copy them out, then on any Linux box:
$ xxd -r -p pub.hex > pub.raw          # 65 bytes: 04 || X || Y
$ printf '3059301306072a8648ce3d020106082a8648ce3d030107034200' \
    | xxd -r -p > spki.der
$ cat spki.der pub.raw > pubkey.der
$ openssl ec -pubin -inform DER -in pubkey.der -out pubkey.pem
read EC key
writing EC key

# The TA emits raw r||s; OpenSSL wants DER. (CNG in the Windows
# driver took the raw form directly - chapter 38.)
$ python3 - "$(cat sig.txt)" <<'EOF' > sig.der
import sys, binascii
raw = binascii.unhexlify(sys.argv[1].strip())
r, s = raw[:32], raw[32:]
def der_int(b):
    b = b.lstrip(b'\x00') or b'\x00'
    if b[0] & 0x80: b = b'\x00' + b
    return b'\x02' + bytes([len(b)]) + b
body = der_int(r) + der_int(s)
sys.stdout.buffer.write(b'\x30' + bytes([len(body)]) + body)
EOF

$ printf 'hello from windows\r\n' > msg.txt   # note CRLF - Windows echo
$ openssl dgst -sha256 -verify pubkey.pem -signature sig.der msg.txt
Verified OK

# THAT is the result. A signature over a digest computed by CNG in
# a Windows ARM64 kernel driver, made by a key generated inside an
# OP-TEE trusted application written in C++, verified by an
# unrelated tool on a third machine.
The CRLF trap

echo hello from windows > C:\msg.txt writes hello from windows\r\n, and echo also keeps any trailing space before the >. If OpenSSL says Verification Failure, compare the digest the driver printed with sha256sum msg.txt before suspecting the crypto. Nine times out of ten the bytes differ, not the mathematics.
