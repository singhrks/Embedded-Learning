Modern C++ for embedded

A practical assembly of everything in this track: the features worth adopting, the patterns that recur in real firmware, and a coding standard you could hand to a team on Monday.

/* --- 2. A TYPED REGISTER, with compile-time field
       checking --- */
template<uint32_t Addr>
struct Register {
        static uint32_t read()
                { return *reinterpret_cast<volatile uint32_t *>(Addr); }
        static void write(uint32_t v)
                { *reinterpret_cast<volatile uint32_t *>(Addr) = v; }

        template<uint8_t Hi, uint8_t Lo>
        struct Field {
                static_assert(Hi < 32 && Lo <= Hi);
                static constexpr uint32_t mask =
                        ((1u << (Hi - Lo + 1)) - 1) << Lo;

                static uint32_t get()
                        { return (read() & mask) >> Lo; }

                static void set(uint32_t v)
                {
                        write((read() & ~mask)
                              | ((v << Lo) & mask));
                }
        };
};

        using Enable = CTRL::Field<0, 0>;
        using Mode   = CTRL::Field<5, 4>;

        Enable::set(1);
        auto m = Mode::get();

/* --- 3. A STATE MACHINE with variant --------------------- */
        struct Idle {};
        struct Connecting { uint32_t started; };
        struct Connected  { uint8_t session; };
        struct Error      { ErrorCode code; };

        using State = std::variant<Idle, Connecting,
                                   Connected, Error>;

        State next(const State& s, Event e)
        {
                return std::visit([&](const auto& st) -> State {
                        using T = std::decay_t<decltype(st)>;

                        if constexpr (std::is_same_v<T, Idle>) {
                                if (e == Event::Connect)
                                        return Connecting{now()};
                        } else if constexpr (
                                std::is_same_v<T, Connecting>) {
                                if (e == Event::Ack)
                                        return Connected{alloc()};
                                if (now() - st.started > TIMEOUT)
                                        return Error{
                                             ErrorCode::Timeout};
                        }
                        return st;      /* unchanged */
                }, s);
        }

Freestanding C++

Which parts of the language and library survive without an operating system is a defined subset, and knowing its boundary is what lets you use C++ on bare metal with confidence.

/* On bare metal, much of the standard library is unavailable -
   but the LANGUAGE is entirely available, and the
   header-only parts of the library mostly are too.       */

/* AVAILABLE without a hosted implementation: */
        <type_traits>   <limits>      <cstddef>
        <cstdint>       <utility>     <initializer_list>
        <atomic>        <bit>         <concepts>
        <compare>       <ratio>       <array> (mostly)
        <span>          <string_view> (mostly)
        <algorithm>     (the non-allocating parts)
        <chrono>        (the duration parts)
        <optional>      <variant>     (with -fno-exceptions
                                       caveats)

/* WHAT YOU MUST PROVIDE YOURSELF: */
        /* the runtime support the compiler assumes exists */
        extern "C" void __cxa_pure_virtual() { for (;;) ; }
        extern "C" int  __cxa_atexit(void (*)(void *), void *,
                                     void *) { return 0; }
        extern "C" void __cxa_guard_acquire() { }
        /* or build with -fno-use-cxa-atexit
           -fno-threadsafe-statics and avoid needing them */

        /* operator new, if anything uses it - or DELIBERATELY
           OMIT IT so any use is a link error (chapter 14) */
        void *operator new(size_t) = delete;
        void  operator delete(void *) noexcept = delete;

        /* memcpy, memset - the compiler emits calls to these
           even in freestanding mode (compilers chapter 07) */
        extern "C" void *memcpy(void *d, const void *s, size_t n);

/* THE STARTUP SEQUENCE that must run before main: */
        extern void (*__init_array_start[])(void);
        extern void (*__init_array_end[])(void);

        static void call_constructors(void)
        {
                for (auto **p = __init_array_start;
                     p < __init_array_end; p++)
                        (*p)();
        }

   zeroing .bss (compilers chapter 12). If .init_array is
   empty - the goal (chapter 01) - this loop does nothing and
   costs nothing.

/* THE FLAGS: */
        -ffreestanding -fno-exceptions -fno-rtti
        -fno-threadsafe-statics -fno-use-cxa-atexit
        -fno-unwind-tables -fno-asynchronous-unwind-tables

Fixed-capacity library choices

ETL (Embedded Template Library) gives you the STL's interfaces with fixed capacity and no heap: etl::vector<T, N>, etl::map, etl::string, etl::optional, state machines and message routing. Boost.SML for state machines. fmt or std::to_chars instead of iostreams. tl::expected if you are pre-C++23. Each is header-only and designed for exactly this environment.

A coding standard

Which standard version to target is usually decided by the toolchain available for your platform, and each step brings specific features worth knowing about.

# Embedded C++ Coding Standard
# ============================

## Build flags (mandatory)
  -std=c++17            (or c++20 where the toolchain allows)
  -fno-exceptions -fno-rtti
  -fno-threadsafe-statics -fno-use-cxa-atexit
  -Wall -Wextra -Wpedantic -Werror
  -Wshadow -Wconversion -Wsign-conversion
  -Wnon-virtual-dtor -Wold-style-cast -Wcast-align
  -Wuseless-cast -Wdouble-promotion -Wformat=2
  -Wsuggest-override
  -ffunction-sections -fdata-sections -Wl,--gc-sections

## Forbidden
  - dynamic allocation after initialisation
  - std::string, std::vector, std::map, std::function
  - iostreams
  - exceptions, dynamic_cast, typeid
  - virtual inheritance
  - C-style casts
  - macros where constexpr, inline or a template works
  - `using namespace` at file scope in a header
  - raw owning pointers

## Required
  - every resource wrapped in RAII
  - every single-argument constructor `explicit`
  - `override` on every override
  - `final` on every leaf class
  - `[[nodiscard]]` on every fallible function
  - `const` on every member function that does not mutate
  - `constexpr` wherever it compiles
  - `static_assert` on every struct whose layout matters
  - fixed-width types (uint32_t), never `int` for hardware
  - std::span or std::array at every buffer interface
  - std::chrono for every duration

## Preferred
  - the rule of zero (chapter 03)
  - composition over inheritance
  - templates or variant over virtual, where the type set is
    closed
  - std::expected or an error enum over error codes
  - free functions over member functions where possible
  - anonymous namespaces over `static` at file scope

## Review checklist
  - does it allocate?          (grep for new, make_unique)
  - can it fail silently?      ([[nodiscard]]?)
  - is every path bounded?     (no unbounded loops or waits)
  - is shared state atomic or masked?  (chapter 13)
  - does the binary grow?      (size -A, before and after)

# ONE PAGE. Enforceable by the compiler for most of it, and by
# grep in CI for the rest. That is the point - a standard
# nobody can check is a standard nobody follows.

Migrating a C codebase

Moving an existing C codebase to C++ is rarely a rewrite. It is incremental, and the order in which you introduce features determines whether the transition is smooth or painful.

/* Incremental, in this order - each step is independently
   valuable and independently revertible.                  */

   1. COMPILE THE EXISTING C AS C++. Fix what breaks:
        · implicit void* conversions need casts
        · `class`, `new`, `template` etc. as identifiers
        · stricter enum rules
        · missing casts on malloc
      This alone finds real bugs, and it is the whole step -
      do not change anything else yet.

   2. REPLACE MACROS with constexpr and inline functions.
      Typed, scoped, debuggable.

   3. WRAP RESOURCES IN RAII, one at a time. Each conversion
      removes a class of leak. Start with the ones whose
      cleanup is most often forgotten.

   4. REPLACE ARRAYS AND POINTER PAIRS with std::array and
      std::span at interfaces.

   5. INTRODUCE enum class for state and mode values.

   6. ADD [[nodiscard]] to fallible functions and fix the
      warnings.

   7. REPLACE FUNCTION-POINTER TABLES with templates or
      variant WHERE THE TYPE SET IS CLOSED - and leave them
      alone where it is not.

   8. ONLY THEN consider classes with virtual functions, and
      only where runtime polymorphism is genuinely needed.

/* WHAT NOT TO DO:
     · rewrite everything at once
     · introduce exceptions into a codebase that does not
       expect them
     · use inheritance to share implementation
     · adopt the whole standard library because it is there

/* AND MEASURE AT EVERY STEP:
        size -A before.elf after.elf
        perf stat, or a cycle counter on the target
   A migration that grows the binary by 40% has gone wrong,
   and you want to know which step did it.               */
