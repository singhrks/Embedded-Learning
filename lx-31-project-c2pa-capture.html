Project: a C2PA capture-attestation driver

Content Credentials are only as trustworthy as the moment the shutter closed. This project puts that moment inside the kernel and the signing key inside the secure world, so that a provenance claim is a statement about pixels the hardware actually produced — not about a file someone handed the signer. This chapter builds the capture side; chapter 47 builds the trusted application and the manifest.

What C2PA actually is

C2PA — the Coalition for Content Provenance and Authenticity — standardises a signed metadata block travelling with a media file. Strip away the vocabulary and it is four things.

   A C2PA MANIFEST, from the inside out

   1. ASSERTIONS - statements about the asset
        c2pa.hash.data   a hash over the asset's bytes, with
                         exclusions for the manifest itself.
                         THE HARD BINDING. Everything rests here.
        c2pa.actions     "created", "edited", "colour adjusted"
        stds.exif        camera, lens, exposure
        c2pa.thumbnail   a small preview
        (and ingredients, referencing parent assets)

   2. CLAIM - a CBOR map that lists the assertions by URI and
        hash, names the generator, and picks the signature
        algorithm. The claim is what gets signed.

   3. CLAIM SIGNATURE - a COSE_Sign1 structure over the claim,
        with an X.509 certificate chain in the protected header.

   4. MANIFEST STORE - all of the above packed into JUMBF boxes
        and embedded in the file (an APP11 segment in JPEG, an
        iTXt/eXIf-adjacent box in PNG, a uuid box in BMFF).

   THE CHAIN OF REASONING A VERIFIER FOLLOWS:

     the certificate chains to a trusted root
       -> so I know who signed
     the COSE_Sign1 signature is valid over the claim
       -> so the claim is what the signer said
     each assertion's hash matches the assertion bytes
       -> so the assertion list is intact
     c2pa.hash.data matches the asset's actual bytes
       -> so THIS FILE is the file that was signed

   Break any link and the credential is invalid. Notice what
   the chain does NOT establish: that the pixels depict
   reality. C2PA proves PROVENANCE, not TRUTH.

The problem hardware solves

This project is more advanced than the earlier two and solves a real problem: proving that an image came from a particular camera and has not been altered since. Start here, with why software alone cannot do it.

   THE NAIVE CAMERA

   sensor -> kernel -> user space -> signing library -> file
                          ^
                          |
                     an attacker with code execution here
                     substitutes any image they like, and the
                     signature over it is PERFECTLY VALID.

   The credential now says "this device produced this image",
   with a real device key, and it is a lie. The signature is
   not forged; it is genuine, over forged content.

   THIS IS THE ENTIRE THREAT. A device signing key protects
   against someone ELSE claiming to be your camera. It does
   nothing about your camera being told to sign a picture it
   never took.

   WHAT ACTUALLY HELPS

   sensor -> kernel ----------------+
               |  hash the frame    |
               |  HERE, before any  |
               |  user process can  |
               |  see it            |
               v                    |
        +--------------+            |
        | attest(hash) |            |
        +------+-------+            |
               | SMC                | frame bytes
               v                    v
        +-------------------+   user space assembles the
        | TA remembers the  |   manifest, and asks the TA
        | hashes it has     |   to sign the claim
        | witnessed         |
        |                   |<-- sign(claim)
        | REFUSES to sign a |
        | claim whose hard  |    the TA parses out the
        | binding is not on |    c2pa.hash.data value and
        | that list         |    checks it against its list
        +-------------------+

   Now user space can still lie about EXIF, about the title,
   about anything soft. It cannot get a signature over an image
   the kernel did not hash.
The design idea worth taking away

A signing service that signs whatever it is given proves only that the key was available. Binding the signature to something the lower layer witnessed is what turns a key into an attestation. The same pattern is a TPM quote (OP-TEE chapter 23), a measured-boot PCR, and a secure-element camera credential.

What this does not defend against

A compromised kernel can attest whatever it likes — the kernel is inside the trust boundary by construction, which is why real camera implementations put the hash even lower, in the ISP or the sensor package. A compromised TA is game over. And nothing here stops someone photographing a screen: C2PA never claimed to. State the boundary honestly whenever you describe such a system, because the marketing around Content Credentials frequently does not.

The ABI

As always, the interface user space depends on is defined first and separately — and here it matters more than usual, because the whole security property depends on what this interface does and does not allow.

/* include/uapi/linux/c2pa_capture.h
 *
 * Shared by the driver, the user-space tool and (via the command
 * ids at the bottom) the trusted application.
 */

#ifndef _UAPI_LINUX_C2PA_CAPTURE_H
#define _UAPI_LINUX_C2PA_CAPTURE_H

#include <linux/types.h>
#include <linux/ioctl.h>

#define C2PA_ABI_VERSION   1
#define C2PA_HASH_LEN      32      /* SHA-256                    */
#define C2PA_SIG_LEN       64      /* ES256: raw r || s          */
#define C2PA_PUBKEY_LEN    64      /* P-256: X || Y              */
#define C2PA_MAX_SIGSTRUCT 4096    /* a COSE Sig_structure       */

/* One capture. The driver fills this in; user space never gets
 * to choose any of it except by asking for another capture.
 */
struct c2pa_capture {
	__u32 version;          /* in:  C2PA_ABI_VERSION            */
	__u32 frame_len;        /* in:  capacity   out: bytes       */
	__u64 frame;            /* in:  user pointer to the buffer  */

	__u64 capture_id;       /* out: TA monotonic counter value  */
	__u64 timestamp_ns;     /* out: CLOCK_MONOTONIC at capture  */
	__u32 width;            /* out                              */
	__u32 height;           /* out                              */
	__u8  hash[C2PA_HASH_LEN];  /* out: SHA-256 of frame bytes  */
};

/* Ask the TA to sign a COSE Sig_structure. The TA will refuse
 * unless the claim it contains binds to a hash it witnessed.
 */
struct c2pa_sign {
	__u32 version;
	__u32 sigstruct_len;
	__u64 sigstruct;        /* in:  user pointer                */
	__u8  binding[C2PA_HASH_LEN];  /* in: the c2pa.hash.data
	                                *     value in this claim   */
	__u8  signature[C2PA_SIG_LEN]; /* out: raw r || s           */
};

struct c2pa_pubkey {
	__u32 version;
	__u32 reserved;
	__u8  pubkey[C2PA_PUBKEY_LEN];   /* out: X || Y            */
};

#define C2PA_IOC_MAGIC   'C'
#define C2PA_IOC_CAPTURE _IOWR(C2PA_IOC_MAGIC, 1, struct c2pa_capture)
#define C2PA_IOC_SIGN    _IOWR(C2PA_IOC_MAGIC, 2, struct c2pa_sign)
#define C2PA_IOC_PUBKEY  _IOWR(C2PA_IOC_MAGIC, 3, struct c2pa_pubkey)

/* Commands on the far side of the SMC. Separate numbering from
 * the ioctls on purpose: the driver translates, and the two
 * interfaces version independently.
 */
#define TA_CMD_GET_PUBKEY     0
#define TA_CMD_ATTEST_CAPTURE 1
#define TA_CMD_SIGN_CLAIM     2

#endif /* _UAPI_LINUX_C2PA_CAPTURE_H */
Why binding is a separate field

The TA could parse the CBOR claim out of the Sig_structure and find c2pa.hash.data itself. It deliberately does not: a CBOR parser inside a TA is a large, attacker-reachable piece of code (OP-TEE chapter 20). Instead user space declares the binding, the TA checks that declaration against its witnessed list, and — the part that makes it sound — chapter 47 shows the TA also verifying that the declared binding actually appears in the bytes it is about to sign, with a fixed-offset memcmp rather than a parser.

The driver

The driver ties together the character-device work from chapter 22, the TEE client interface, and the crypto path. It is long; the annotations mark the parts that carry the security property.

// SPDX-License-Identifier: GPL-2.0
/*
 * c2pa_capture.c - a C2PA capture-attestation test driver.
 *
 * Produces synthetic frames, hashes them in the kernel, and has
 * an OP-TEE trusted application witness each hash before user
 * space ever sees the pixels.
 *
 * On real hardware the frame source is a V4L2 subdev or an ISP
 * DMA completion; everything else is unchanged.
 */

#include <linux/module.h>
#include <linux/miscdevice.h>
#include <linux/fs.h>
#include <linux/slab.h>
#include <linux/uaccess.h>
#include <linux/mutex.h>
#include <linux/tee_drv.h>
#include <linux/uuid.h>
#include <linux/crypto.h>
#include <crypto/hash.h>
#include <linux/ktime.h>
#include <uapi/linux/c2pa_capture.h>

#define DRV_NAME "c2pa-capture"

/* 8b1e4d72-3f5a-4c26-9d80-6a7b2e14f903 */
#define C2PA_TA_UUID UUID_INIT(0x8b1e4d72, 0x3f5a, 0x4c26, \
			       0x9d, 0x80, 0x6a, 0x7b, \
			       0x2e, 0x14, 0xf9, 0x03)

#define FRAME_W   640
#define FRAME_H   480
#define FRAME_LEN (FRAME_W * FRAME_H * 3)      /* RGB888        */
#define SHM_SIZE  8192

struct c2pa_dev {
	struct miscdevice	misc;
	struct mutex		lock;		/* one request at a time */

	/* TEE plumbing */
	struct tee_context	*ctx;
	u32			session;
	struct tee_shm		*shm;
	void			*shm_va;

	/* crypto */
	struct crypto_shash	*tfm;

	/* frame source */
	u8			*frame;
	u32			frame_no;
};

static struct c2pa_dev *g_dev;

/* ------------------------------------------------------------------
 * TEE glue
 * ------------------------------------------------------------------ */

static int optee_match(struct tee_ioctl_version_data *ver, const void *data)
{
	return ver->impl_id == TEE_IMPL_ID_OPTEE;
}

static int c2pa_tee_init(struct c2pa_dev *d)
{
	struct tee_ioctl_open_session_arg arg = { };
	uuid_t uuid = C2PA_TA_UUID;
	int rc;

	d->ctx = tee_client_open_context(NULL, optee_match, NULL, NULL);
	if (IS_ERR(d->ctx)) {
		/* -ENOENT during boot means OP-TEE is not up yet. */
		rc = PTR_ERR(d->ctx);
		d->ctx = NULL;
		return rc == -ENOENT ? -EPROBE_DEFER : rc;
	}

	export_uuid(arg.uuid, &uuid);
	/*
	 * REE_KERNEL, not PUBLIC. The TA uses the login type to
	 * decide who may ATTEST: only the kernel may say "I saw this
	 * frame". A user-space process opening its own session gets
	 * LOGIN_USER and is refused (chapter 47).
	 */
	arg.clnt_login = TEE_IOCTL_LOGIN_REE_KERNEL;
	arg.num_params = 0;

	rc = tee_client_open_session(d->ctx, &arg, NULL);
	if (rc < 0 || arg.ret != 0) {
		pr_err(DRV_NAME ": open_session rc=%d ret=0x%08x\n",
		       rc, arg.ret);
		tee_client_close_context(d->ctx);
		d->ctx = NULL;
		return rc < 0 ? rc : -EINVAL;
	}
	d->session = arg.session;

	d->shm = tee_shm_alloc_kernel_buf(d->ctx, SHM_SIZE);
	if (IS_ERR(d->shm)) {
		rc = PTR_ERR(d->shm);
		d->shm = NULL;
		tee_client_close_session(d->ctx, d->session);
		tee_client_close_context(d->ctx);
		d->ctx = NULL;
		return rc;
	}
	d->shm_va = tee_shm_get_va(d->shm, 0);
	if (IS_ERR(d->shm_va))
		return PTR_ERR(d->shm_va);

	return 0;
}

static void c2pa_tee_exit(struct c2pa_dev *d)
{
	/* Reverse order of init, always. */
	if (d->shm)
		tee_shm_free(d->shm);
	if (d->ctx) {
		tee_client_close_session(d->ctx, d->session);
		tee_client_close_context(d->ctx);
	}
}

/* GlobalPlatform TEE_Result -> errno, in one place. */
static int tee_result_to_errno(u32 res)
{
	switch (res) {
	case 0xFFFF0004: return -EOPNOTSUPP;	/* NOT_SUPPORTED    */
	case 0xFFFF0006: return -EINVAL;	/* BAD_PARAMETERS   */
	case 0xFFFF0008: return -ENOENT;	/* ITEM_NOT_FOUND   */
	case 0xFFFF000C: return -ENOSPC;	/* SHORT_BUFFER     */
	case 0xFFFF000F: return -EACCES;	/* ACCESS_DENIED    */
	case 0xFFFF3024: return -ENOMEM;	/* OUT_OF_MEMORY    */
	case 0xFFFF3110: return -ENODEV;	/* TARGET_DEAD      */
	default:         return -EIO;
	}
}

/* ------------------------------------------------------------------
 * The frame source
 *
 * A moving test pattern, so successive captures differ and you can
 * see the hash change. Replace with a V4L2 buffer on real hardware.
 * ------------------------------------------------------------------ */
static void c2pa_generate_frame(struct c2pa_dev *d)
{
	u32 x, y;
	u8 *p = d->frame;

	for (y = 0; y < FRAME_H; y++) {
		for (x = 0; x < FRAME_W; x++) {
			*p++ = (u8)(x + d->frame_no);		/* R */
			*p++ = (u8)(y + d->frame_no * 2);	/* G */
			*p++ = (u8)((x ^ y) + d->frame_no);	/* B */
		}
	}
	d->frame_no++;
}

/* ------------------------------------------------------------------
 * Hashing, with the kernel crypto API
 * ------------------------------------------------------------------ */
static int c2pa_hash_frame(struct c2pa_dev *d, u8 out[C2PA_HASH_LEN])
{
	SHASH_DESC_ON_STACK(desc, d->tfm);

	desc->tfm = d->tfm;
	return crypto_shash_digest(desc, d->frame, FRAME_LEN, out);
	/*
	 * The frame is hashed HERE, from the kernel's own buffer,
	 * before copy_to_user. That ordering is the whole security
	 * argument: there is no window in which user space could
	 * substitute pixels between the hash and the attestation.
	 */
}

/* ------------------------------------------------------------------
 * C2PA_IOC_CAPTURE
 * ------------------------------------------------------------------ */
static long c2pa_do_capture(struct c2pa_dev *d, unsigned long arg)
{
	struct c2pa_capture req;
	struct tee_ioctl_invoke_arg inv = { };
	struct tee_param param[4] = { };
	u8 hash[C2PA_HASH_LEN];
	u64 timestamp;
	int rc;

	if (copy_from_user(&req, (void __user *)arg, sizeof(req)))
		return -EFAULT;
	if (req.version != C2PA_ABI_VERSION)
		return -EINVAL;
	if (req.frame_len < FRAME_LEN)
		return -ENOSPC;

	mutex_lock(&d->lock);

	c2pa_generate_frame(d);

	rc = c2pa_hash_frame(d, hash);
	if (rc)
		goto out;

	timestamp = ktime_get_ns();

	/*
	 * Attest: hand the hash to the TA. It records it and returns
	 * its monotonic counter as a capture id.
	 *
	 * param[0] memref in  : the 32-byte hash
	 * param[1] value out  : a = counter low, b = counter high
	 */
	memcpy(d->shm_va, hash, C2PA_HASH_LEN);

	param[0].attr = TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_INPUT;
	param[0].u.memref.shm      = d->shm;
	param[0].u.memref.shm_offs = 0;
	param[0].u.memref.size     = C2PA_HASH_LEN;
	param[1].attr = TEE_IOCTL_PARAM_ATTR_TYPE_VALUE_OUTPUT;

	inv.func       = TA_CMD_ATTEST_CAPTURE;
	inv.session    = d->session;
	inv.num_params = 4;

	rc = tee_client_invoke_func(d->ctx, &inv, param);
	if (rc < 0)
		goto out;
	if (inv.ret != 0) {
		pr_warn(DRV_NAME ": attest returned 0x%08x\n", inv.ret);
		rc = tee_result_to_errno(inv.ret);
		goto out;
	}

	req.capture_id   = (u64)param[1].u.value.a |
			   ((u64)param[1].u.value.b << 32);
	req.timestamp_ns = timestamp;
	req.width        = FRAME_W;
	req.height       = FRAME_H;
	req.frame_len    = FRAME_LEN;
	memcpy(req.hash, hash, C2PA_HASH_LEN);

	/*
	 * Only NOW does user space get the pixels - after the TA has
	 * already committed to their hash.
	 */
	if (copy_to_user((void __user *)req.frame, d->frame, FRAME_LEN)) {
		rc = -EFAULT;
		goto out;
	}
	if (copy_to_user((void __user *)arg, &req, sizeof(req)))
		rc = -EFAULT;
out:
	mutex_unlock(&d->lock);
	return rc;
}

/* ------------------------------------------------------------------
 * C2PA_IOC_SIGN
 * ------------------------------------------------------------------ */
static long c2pa_do_sign(struct c2pa_dev *d, unsigned long arg)
{
	struct c2pa_sign req;
	struct tee_ioctl_invoke_arg inv = { };
	struct tee_param param[4] = { };
	void *sigstruct = NULL;
	long rc;

	if (copy_from_user(&req, (void __user *)arg, sizeof(req)))
		return -EFAULT;
	if (req.version != C2PA_ABI_VERSION)
		return -EINVAL;
	if (req.sigstruct_len == 0 ||
	    req.sigstruct_len > C2PA_MAX_SIGSTRUCT)
		return -EINVAL;
	/* Leave room for the binding at a fixed offset in the SHM. */
	if (req.sigstruct_len + C2PA_HASH_LEN > SHM_SIZE)
		return -EINVAL;

	sigstruct = memdup_user((void __user *)req.sigstruct,
				req.sigstruct_len);
	if (IS_ERR(sigstruct))
		return PTR_ERR(sigstruct);

	mutex_lock(&d->lock);

	/*
	 * Shared memory layout for this call:
	 *   [0                .. sigstruct_len)  the Sig_structure
	 *   [sigstruct_len    .. +32)            the declared binding
	 * Two partial memrefs over one buffer (OP-TEE chapter 7).
	 */
	memcpy(d->shm_va, sigstruct, req.sigstruct_len);
	memcpy((u8 *)d->shm_va + req.sigstruct_len,
	       req.binding, C2PA_HASH_LEN);

	param[0].attr = TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_INPUT;
	param[0].u.memref.shm      = d->shm;
	param[0].u.memref.shm_offs = 0;
	param[0].u.memref.size     = req.sigstruct_len;

	param[1].attr = TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_INPUT;
	param[1].u.memref.shm      = d->shm;
	param[1].u.memref.shm_offs = req.sigstruct_len;
	param[1].u.memref.size     = C2PA_HASH_LEN;

	param[2].attr = TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_OUTPUT;
	param[2].u.memref.shm      = d->shm;
	param[2].u.memref.shm_offs = SHM_SIZE - C2PA_SIG_LEN;
	param[2].u.memref.size     = C2PA_SIG_LEN;

	inv.func       = TA_CMD_SIGN_CLAIM;
	inv.session    = d->session;
	inv.num_params = 4;

	rc = tee_client_invoke_func(d->ctx, &inv, param);
	if (rc < 0)
		goto out;
	if (inv.ret != 0) {
		/*
		 * ACCESS_DENIED here is the interesting one: it means
		 * the TA refused because the declared binding is not a
		 * hash it witnessed. That is the system working.
		 */
		pr_warn(DRV_NAME ": sign returned 0x%08x\n", inv.ret);
		rc = tee_result_to_errno(inv.ret);
		goto out;
	}

	memcpy(req.signature, (u8 *)d->shm_va + SHM_SIZE - C2PA_SIG_LEN,
	       C2PA_SIG_LEN);
	rc = copy_to_user((void __user *)arg, &req, sizeof(req)) ? -EFAULT : 0;
out:
	mutex_unlock(&d->lock);
	kfree(sigstruct);
	return rc;
}

/* ------------------------------------------------------------------
 * C2PA_IOC_PUBKEY
 * ------------------------------------------------------------------ */
static long c2pa_do_pubkey(struct c2pa_dev *d, unsigned long arg)
{
	struct c2pa_pubkey req;
	struct tee_ioctl_invoke_arg inv = { };
	struct tee_param param[4] = { };
	long rc;

	if (copy_from_user(&req, (void __user *)arg, sizeof(req)))
		return -EFAULT;
	if (req.version != C2PA_ABI_VERSION)
		return -EINVAL;

	mutex_lock(&d->lock);

	param[0].attr = TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_OUTPUT;
	param[0].u.memref.shm      = d->shm;
	param[0].u.memref.shm_offs = 0;
	param[0].u.memref.size     = C2PA_PUBKEY_LEN;

	inv.func       = TA_CMD_GET_PUBKEY;
	inv.session    = d->session;
	inv.num_params = 4;

	rc = tee_client_invoke_func(d->ctx, &inv, param);
	if (rc < 0)
		goto out;
	if (inv.ret != 0) {
		rc = tee_result_to_errno(inv.ret);
		goto out;
	}

	memcpy(req.pubkey, d->shm_va, C2PA_PUBKEY_LEN);
	rc = copy_to_user((void __user *)arg, &req, sizeof(req)) ? -EFAULT : 0;
out:
	mutex_unlock(&d->lock);
	return rc;
}

/* ------------------------------------------------------------------
 * File operations
 * ------------------------------------------------------------------ */
static long c2pa_ioctl(struct file *f, unsigned int cmd, unsigned long arg)
{
	struct c2pa_dev *d = g_dev;

	switch (cmd) {
	case C2PA_IOC_CAPTURE: return c2pa_do_capture(d, arg);
	case C2PA_IOC_SIGN:    return c2pa_do_sign(d, arg);
	case C2PA_IOC_PUBKEY:  return c2pa_do_pubkey(d, arg);
	default:               return -ENOTTY;
	}
}

static const struct file_operations c2pa_fops = {
	.owner		= THIS_MODULE,
	.unlocked_ioctl	= c2pa_ioctl,
	.compat_ioctl	= compat_ptr_ioctl,   /* the structs use __u64
					       * for pointers, so 32-bit
					       * user space needs nothing
					       * more than this           */
	.llseek		= no_llseek,
};

/* ------------------------------------------------------------------
 * Module init / exit
 * ------------------------------------------------------------------ */
static int __init c2pa_init(void)
{
	struct c2pa_dev *d;
	int rc;

	d = kzalloc(sizeof(*d), GFP_KERNEL);
	if (!d)
		return -ENOMEM;
	mutex_init(&d->lock);

	d->frame = vmalloc(FRAME_LEN);
	if (!d->frame) {
		rc = -ENOMEM;
		goto err_free;
	}

	d->tfm = crypto_alloc_shash("sha256", 0, 0);
	if (IS_ERR(d->tfm)) {
		rc = PTR_ERR(d->tfm);
		pr_err(DRV_NAME ": no sha256 shash: %d\n", rc);
		goto err_frame;
	}

	rc = c2pa_tee_init(d);
	if (rc)
		goto err_tfm;

	d->misc.minor = MISC_DYNAMIC_MINOR;
	d->misc.name  = "c2pa0";
	d->misc.fops  = &c2pa_fops;
	d->misc.mode  = 0600;      /* root only: attestation is not
				    * something every process should be
				    * able to consume                 */

	rc = misc_register(&d->misc);
	if (rc)
		goto err_tee;

	g_dev = d;
	pr_info(DRV_NAME ": /dev/c2pa0 ready\n");
	return 0;

err_tee:
	c2pa_tee_exit(d);
err_tfm:
	crypto_free_shash(d->tfm);
err_frame:
	vfree(d->frame);
err_free:
	kfree(d);
	return rc;
}

static void __exit c2pa_exit(void)
{
	struct c2pa_dev *d = g_dev;

	misc_deregister(&d->misc);
	c2pa_tee_exit(d);
	crypto_free_shash(d->tfm);
	vfree(d->frame);
	kfree(d);
	g_dev = NULL;
}

module_init(c2pa_init);
module_exit(c2pa_exit);

MODULE_DESCRIPTION("C2PA capture attestation, backed by OP-TEE");
MODULE_LICENSE("GPL");
The ordering that carries the whole argument

In c2pa_do_capture: generate, hash, attest, then copy_to_user. Move the copy earlier — which looks harmless, and which a later refactor will be tempted to do — and a second thread sharing the buffer could in principle observe or race the pixels before the TA has committed to their hash. Comment the ordering in the code, not just in the design document, because that is where the next person edits.

Building and loading

This project needs more than a kernel: a secure world running alongside it. These are the pieces and the order to bring them up in.

# Kbuild
obj-m += c2pa_capture.o
ccflags-y += -I$(src)/include

# Build against the OP-TEE QEMU kernel (OP-TEE chapter 4).
$ cd ~/optee/linux
$ ./scripts/config --enable TEE --enable OPTEE \
                   --enable CRYPTO_SHA256 --enable CRYPTO_USER_API_HASH
$ make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- olddefconfig
$ make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- -j$(nproc) Image modules

A smoke test before the manifest work

Before writing any of the manifest code, confirm the foundation works end to end. Debugging a signature problem is far easier when you already know the plumbing beneath it is sound.

/* tools/c2pa-smoke.c - proves the driver and TA agree before you
 * go anywhere near CBOR. Build it first, always.
 */
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include "c2pa_capture.h"

static void hex(const char *label, const unsigned char *p, size_t n)
{
	printf("%-12s", label);
	for (size_t i = 0; i < n; i++)
		printf("%02x", p[i]);
	printf("\n");
}

int main(void)
{
	int fd = open("/dev/c2pa0", O_RDWR);
	if (fd < 0) { perror("/dev/c2pa0"); return 1; }

	/* 1. Who is the camera? */
	struct c2pa_pubkey pk = { .version = C2PA_ABI_VERSION };
	if (ioctl(fd, C2PA_IOC_PUBKEY, &pk)) { perror("PUBKEY"); return 1; }
	hex("pubkey", pk.pubkey, sizeof(pk.pubkey));

	/* 2. Capture. */
	unsigned char *frame = malloc(640 * 480 * 3);
	struct c2pa_capture cap = {
		.version   = C2PA_ABI_VERSION,
		.frame_len = 640 * 480 * 3,
		.frame     = (unsigned long long)(uintptr_t)frame,
	};
	if (ioctl(fd, C2PA_IOC_CAPTURE, &cap)) { perror("CAPTURE"); return 1; }
	printf("capture id  %llu  %ux%u\n",
	       (unsigned long long)cap.capture_id, cap.width, cap.height);
	hex("frame hash", cap.hash, sizeof(cap.hash));

	/* 3. Sign something that DOES bind to that capture. */
	unsigned char fake_sigstruct[64];
	memset(fake_sigstruct, 0xAB, sizeof(fake_sigstruct));

	struct c2pa_sign s = {
		.version       = C2PA_ABI_VERSION,
		.sigstruct_len = sizeof(fake_sigstruct),
		.sigstruct     = (unsigned long long)(uintptr_t)fake_sigstruct,
	};
	memcpy(s.binding, cap.hash, C2PA_HASH_LEN);

	if (ioctl(fd, C2PA_IOC_SIGN, &s)) { perror("SIGN (valid)"); return 1; }
	hex("signature", s.signature, sizeof(s.signature));

	/* 4. And now something that does NOT. This MUST fail. */
	s.binding[0] ^= 0xff;
	if (ioctl(fd, C2PA_IOC_SIGN, &s) == 0) {
		fprintf(stderr, "FAIL: TA signed an unwitnessed binding!\n");
		return 1;
	}
	printf("refused an unwitnessed binding, as it should\n");

	close(fd);
	return 0;
}
