Project: a full-stack secure signing service in Rust

One request travels through four privilege domains — a user-mode driver, a kernel driver, the secure monitor, and a trusted application — and comes back with a signature made by a key that never existed in normal-world memory. Every line of it is Rust. OpenSSL, in the normal world, then verifies that signature, which is how you know the whole chain is real and not merely self-consistent.

Where this sits

Harder than the key store, which talked to its TA directly from user space. Easier than the fTPM, which integrated forty thousand lines of someone else's C. The new idea here is the kernel driver in the middle, and the language is the other new idea.

What we are building

The final project revisits the secure-signing problem in Rust on both sides, which is worth doing because memory safety matters more in trusted code than anywhere else in this curriculum.

   NORMAL WORLD                                SECURE WORLD

   +-------------------------------------+
   | rsecctl  (EL0, Rust, std)           |

                                               |   * ECDSA sign - GP API    |

   THE PROPERTY WE ARE ENFORCING:

     the private key is generated by the TA, stored by the TA,
     and used by the TA. No layer above it - not the kernel
     driver, not root, not a kernel exploit - can read it,
     because it is never in a page the normal world can map.

   THE PROPERTY WE ARE PROVING:

     OpenSSL, a program that knows nothing about OP-TEE,
     verifies the signature against the public key. If that
     passes, the TA is doing real ECDSA over the real digest.

Why put a kernel driver in the middle at all?

The key store project called libteec straight from user space and worked perfectly. Adding a kernel layer is not free — it is a module to maintain, an ioctl ABI to freeze, and a new place for bugs. It earns its place for four reasons, and if none of them apply to your problem you should skip it.

ReasonWhat it buys
The kernel itself is a consumerdm-crypt wants a key, IMA wants to extend a measurement, the RNG wants entropy. Kernel code cannot call libteec — it must use the in-kernel client API
Policy and serialisationOne TA session shared by every caller, with a mutex, instead of every process opening its own. OP-TEE has a fixed thread pool (chapter 5); uncontrolled session creation exhausts it
A standard interfacePresent the service as a device, an hwrng, a crypto_alg or a TPM, and existing tools work unmodified — exactly what the fTPM driver does
The data is kernel-ownedA measurement taken from a device the kernel owns must not be laundered through user space on its way to the TEE, or the value proves nothing
The cost, stated honestly

Every request now crosses user→kernel and normal→secure. On QEMU expect tens of microseconds per round trip; the extra syscall is noise next to the world switch. What the kernel layer really costs you is an ABI you can never change, which is why the ioctl design below gets a section to itself.

Where the cryptography lives

The brief says "cryptographic operations done with OpenSSL". That is right, and it belongs in the normal world — not inside the TA. This is worth being explicit about because it is a design decision, not a limitation I am working around.

   OPENSSL, in rsecctl, normal world:

     SHA-256 over the file             bulk data. Megabytes.
                                       Hashing is not secret and
                                       moving megabytes through
                                       shared memory into a TA
                                       would be slow and pointless.

     raw r||s  ->  DER SEQUENCE        a format conversion.
                                       No secrets involved.

     ECDSA VERIFY                      uses the PUBLIC key. There
                                       is nothing to protect.

     SubjectPublicKeyInfo / PEM        packaging, for the rest of
                                       the world to consume.

   THE TA, secure world, GP Internal API:

     key generation                    the private key must come
                                       into existence inside the
                                       boundary or the whole
                                       exercise is theatre.

     key storage                       secure storage, sealed to
                                       the HUK (chapter 15).

     ECDSA SIGN over a 32-byte digest  the only operation that
                                       touches the private key.

   THE RULE, which generalises far beyond this project:

     put in the TEE exactly what must not leak, and nothing
     else. Every extra byte and every extra line inside the
     boundary is attack surface (chapter 20) and secure RAM
     you do not have (chapter 6).

   And note what is NOT possible: linking OpenSSL into a TA.
   A TA is S-EL0 with no OS, no sockets, no files, a few
   hundred KB of heap and a libc subset. The fTPM manages it
   with wolfSSL and a 2 MB heap (chapter 22) and that is a
   serious undertaking. Use the GP crypto API inside; use
   OpenSSL outside.

The ABI: the part you cannot change later

The boundary between Rust and the C interfaces of the TEE is where the safety guarantees stop, so it is the part that needs the most care and the clearest encapsulation.

// crates/rsec-abi/src/lib.rs
//
// Shared by all three layers. The kernel module and the user
// program both depend on this crate, so a change that breaks
// one fails to compile the other. That is the entire point of
// putting it in a crate instead of writing the numbers twice.

#![cfg_attr(not(feature = "std"), no_std)]

pub const RSEC_ABI_VERSION: u32 = 1;

/// ioctl "type" byte. Anything unclaimed in
/// Documentation/userspace-api/ioctl/ioctl-number.rst will do.
pub const RSEC_IOC_MAGIC: u32 = 0xE7;

// ---------------------------------------------------------------
// ioctl encoding, asm-generic (arm64, x86, riscv - not sparc/ppc)
//
//   bits 31..30  direction   1 = write, 2 = read, 3 = both
//   bits 29..16  size of the argument struct
//   bits 15..8   type
//   bits  7..0   number
//
// We compute these by hand rather than pulling in a macro crate,
// because the kernel side and the user side must agree exactly
// and there is value in seeing the arithmetic once.
// ---------------------------------------------------------------
const DIR_WRITE: u32 = 1;
const DIR_READ:  u32 = 2;

const fn ioc(dir: u32, nr: u32, size: usize) -> u32 {
    (dir << 30) | ((size as u32) << 16) | (RSEC_IOC_MAGIC << 8) | nr
}
const fn iowr(nr: u32, size: usize) -> u32 {
    ioc(DIR_READ | DIR_WRITE, nr, size)
}

/// Fetch the P-256 public key as 64 raw bytes: X || Y.
#[repr(C)]
#[derive(Debug, Clone, Copy, Default)]
pub struct RsecPubkey {
    /// Caller writes RSEC_ABI_VERSION. Kernel rejects anything else.
    pub version: u32,
    /// Caller writes the capacity of `buf`; kernel writes back
    /// the number of bytes produced.
    pub len:     u32,
    /// User pointer, as a u64 so the struct is the same size for
    /// 32-bit and 64-bit user space. See the note below.
    pub buf:     u64,
}

/// Sign one SHA-256 digest. Returns raw r || s, 64 bytes.
#[repr(C)]
#[derive(Debug, Clone, Copy)]
pub struct RsecSign {
    pub version: u32,
    /// in: capacity of `sig`; out: bytes written
    pub sig_len: u32,
    /// The digest travels INLINE. It is 32 bytes; a pointer plus
    /// a length would be more code and more to validate.
    pub digest:  [u8; 32],
    pub sig:     u64,
}

/// Read, and optionally increment, the monotonic counter.
#[repr(C)]
#[derive(Debug, Clone, Copy, Default)]
pub struct RsecCounter {
    pub version:   u32,
    /// 1 = increment before reading, 0 = read only
    pub increment: u32,
    /// out
    pub value:     u64,
}

pub const RSEC_IOC_PUBKEY:  u32 = iowr(1, core::mem::size_of::<RsecPubkey>());
pub const RSEC_IOC_SIGN:    u32 = iowr(2, core::mem::size_of::<RsecSign>());
pub const RSEC_IOC_COUNTER: u32 = iowr(3, core::mem::size_of::<RsecCounter>());

// Command ids on the TEE side. Deliberately separate from the
// ioctl numbers: the kernel is a translator, not a pass-through,
// and the two ABIs are allowed to evolve independently.
pub const TA_CMD_GET_PUBKEY: u32 = 0;
pub const TA_CMD_SIGN:       u32 = 1;
pub const TA_CMD_COUNTER:    u32 = 2;

pub const RSEC_TA_UUID: &str = "7f2e5c10-9a41-4b8d-b3c6-1e0d5a72f491";

pub const PUBKEY_LEN: usize = 64;   // P-256: 32-byte X, 32-byte Y
pub const SIG_LEN:    usize = 64;   // P-256: 32-byte r, 32-byte s
pub const DIGEST_LEN: usize = 32;   // SHA-256
Four ABI rules, learned the hard way by everyone

1. Pointers in ioctl structs are u64, never usize or a real pointer type — otherwise a 32-bit process on a 64-bit kernel sends a differently-sized struct and you need a whole compat_ioctl path. 2. Every field is naturally aligned and the struct has no implicit padding, so there are no uninitialised bytes to leak back to user space. 3. A version field is first, always, and the kernel rejects a mismatch. 4. The size is baked into the ioctl number, so a struct that changes size produces ENOTTY rather than silent corruption.

/// Open the persistent keypair, creating it on first use.
///
/// This is the heart of the project. `TransientObject::generate_key`
/// runs inside S-EL0; the private scalar is written into secure
/// heap and then into a persistent object that OP-TEE encrypts
/// with a key derived from the hardware unique key (chapter 15).
/// At no point does it exist in a page the normal world can map.
fn open_or_create_key() -> Result<PersistentObject> {
    // Fast path: it already exists.
    match PersistentObject::open(
        ObjectStorageConstants::Private,
        KEY_OBJECT_ID,
        DataFlag::ACCESS_READ,
    ) {
        Ok(obj) => return Ok(obj),
        Err(e) if e.kind() == ErrorKind::ItemNotFound => {}
        Err(e) => return Err(e),
    }

    trace_println!("[rsec-ta] generating a new P-256 keypair");

    let mut key = TransientObject::allocate(
        TransientObjectType::EcdsaKeypair,
        P256_BITS as usize,
    )?;

    // The curve is an ATTRIBUTE of the generation, not of the type.
    // Forget this and you get TEE_ERROR_NOT_SUPPORTED with no clue
    // as to why.
    let curve = Attribute::from_value(
        AttributeId::EccCurve,
        optee_utee_sys::TEE_ECC_CURVE_NIST_P256,
        0,
    );
    key.generate_key(P256_BITS as usize, &[curve])?;

    // Persist the OBJECT. Note we do not serialise the private
    // scalar into a buffer and write bytes - that would put it in
    // TA memory in the clear, briefly, for no reason.
    let obj = PersistentObject::create(
        ObjectStorageConstants::Private,
        KEY_OBJECT_ID,
        DataFlag::ACCESS_READ | DataFlag::ACCESS_WRITE_META,
        Some(&mut key),
        &[],
    )?;

    Ok(obj)
}

// -----------------------------------------------------------------
// TA_CMD_GET_PUBKEY   params: [0] = memref out, 64 bytes
// -----------------------------------------------------------------
fn cmd_get_pubkey(params: &mut Parameters) -> Result<()> {
    let mut p0 = unsafe { params.0.as_memref()? };
    let out = p0.buffer();

    if out.len() < PUBKEY_LEN {
        return Err(Error::new(ErrorKind::ShortBuffer));
    }

    let obj = open_or_create_key()?;

    // X and Y may come back SHORTER than 32 bytes when the value
    // has leading zeros - roughly one time in 256 per coordinate.
    // Left-pad into a fixed 64-byte field so the caller always
    // sees the same layout. Getting this wrong produces a key
    // that works 99% of the time, which is the worst kind of bug.
    let mut x = [0u8; 32];
    let mut y = [0u8; 32];

    let xlen = obj.ref_attribute(AttributeId::EccPublicValueX, &mut x)?;
    let ylen = obj.ref_attribute(AttributeId::EccPublicValueY, &mut y)?;

    let mut pub_raw = [0u8; PUBKEY_LEN];
    pub_raw[32 - xlen..32].copy_from_slice(&x[..xlen]);
    pub_raw[64 - ylen..64].copy_from_slice(&y[..ylen]);

    out[..PUBKEY_LEN].copy_from_slice(&pub_raw);
    p0.set_updated_size(PUBKEY_LEN);
    Ok(())
}

// -----------------------------------------------------------------
// TA_CMD_SIGN   params: [0] = memref in  (32-byte digest)
//                       [1] = memref out (64-byte signature)
// -----------------------------------------------------------------
fn cmd_sign(params: &mut Parameters) -> Result<()> {
    let mut p0 = unsafe { params.0.as_memref()? };
    let mut p1 = unsafe { params.1.as_memref()? };

    let digest_in = p0.buffer();
    let out       = p1.buffer();

    // Exactly 32 bytes or nothing. A fixed size means there is no
    // length arithmetic anywhere in this function to get wrong.
    if digest_in.len() != DIGEST_LEN {
        return Err(Error::new(ErrorKind::BadParameters));
    }
    if out.len() < SIG_LEN {
        return Err(Error::new(ErrorKind::ShortBuffer));
    }

    // ONE fetch out of shared memory into TA memory, then work on
    // the copy (chapter 20). The normal world can rewrite the
    // shared buffer at any instant, including between two reads
    // of the same byte.
    let mut digest = [0u8; DIGEST_LEN];
    digest.copy_from_slice(digest_in);

    let key = open_or_create_key()?;

    let mut op = Asymmetric::allocate(
        AlgorithmId::EcdsaP256,
        OperationMode::Sign,
        P256_BITS as usize,
    )?;
    op.set_key(&key)?;

    let mut sig = [0u8; SIG_LEN];
    let n = op.sign_digest(&[], &digest, &mut sig)?;

    // Write the output ONCE, at the end, on success. A TA that
    // writes partial results into shared memory and then fails
    // has handed the caller something that looks like an answer.
    out[..n].copy_from_slice(&sig[..n]);
    p1.set_updated_size(n);
    Ok(())
}

// -----------------------------------------------------------------
// TA_CMD_COUNTER   params: [0] = value in/out
//                            a = 1 to increment first
//                            b = (out) the counter value
// -----------------------------------------------------------------
fn cmd_counter(params: &mut Parameters) -> Result<()> {
    let mut p0 = unsafe { params.0.as_value()? };
    let do_increment = p0.a() == 1;

    let mut value: u64 = 0;

    match PersistentObject::open(
        ObjectStorageConstants::Private,
        COUNTER_OBJECT_ID,
        DataFlag::ACCESS_READ | DataFlag::ACCESS_WRITE,
    ) {
        Ok(mut obj) => {
            let mut buf = [0u8; 8];
            let n = obj.read(&mut buf)?;
            if n as usize == buf.len() {
                value = u64::from_le_bytes(buf);
            }
            if do_increment {
                value = value.saturating_add(1);
                obj.seek(0, optee_utee::Whence::DataSeekSet)?;
                obj.write(&value.to_le_bytes())?;
            }
        }
        Err(e) if e.kind() == ErrorKind::ItemNotFound => {
            if do_increment {
                value = 1;
            }
            PersistentObject::create(
                ObjectStorageConstants::Private,
                COUNTER_OBJECT_ID,
                DataFlag::ACCESS_READ
                    | DataFlag::ACCESS_WRITE
                    | DataFlag::ACCESS_WRITE_META,
                None,
                &value.to_le_bytes(),
            )?;
        }
        Err(e) => return Err(e),
    }

    // Two 32-bit halves, because a GP value parameter is a pair of
    // u32 and we want a u64 (chapter 12).
    p0.set_a((value & 0xffff_ffff) as u32);
    p0.set_b((value >> 32) as u32);
    Ok(())
}

The kernel driver, in Rust

Rust for Linux gives you a misc device, a mutex and safe user-copy helpers. It does not give you the TEE client API — there is no kernel::tee module upstream. So the first thing this driver does is declare the C functions itself.

//
// Hand-written bindings to drivers/tee's in-kernel client API.
// Everything here is EXPORT_SYMBOL_GPL, so a GPL module may call
// it. See include/linux/tee_drv.h for the authority.
//

/// Accept only OP-TEE, not AMD-TEE or any other back end.
///
/// # Safety
/// Called by the TEE core with a valid `ver` pointer.
pub unsafe extern "C" fn optee_match(
    ver: *mut bindings::tee_ioctl_version_data,
    _data: *const c_void,
) -> core::ffi::c_int {
    // SAFETY: the caller guarantees `ver` points at a live struct.
    let impl_id = unsafe { (*ver).impl_id };
    (impl_id == bindings::TEE_IMPL_ID_OPTEE) as core::ffi::c_int
}

/// Map a GlobalPlatform TEE_Result onto an errno.
///
/// Do this once, in one place. A driver that returns -EINVAL for
/// every TA failure is a driver nobody can debug from user space.
pub fn tee_result_to_errno(res: u32) -> kernel::error::Error {
    use kernel::error::code::*;
    match res {
        0x0000_0000 => EINVAL,        // caller should not be here
        0xFFFF_0004 => ENOSYS,        // NOT_SUPPORTED
        0xFFFF_0006 => EINVAL,        // BAD_PARAMETERS
        0xFFFF_000C => ENOSPC,        // SHORT_BUFFER
        0xFFFF_0008 => ENOENT,        // ITEM_NOT_FOUND
        0xFFFF_000F => EACCES,        // ACCESS_DENIED
        0xFFFF_3024 => ENOMEM,        // OUT_OF_MEMORY
        0xFFFF_3110 => ETIME,         // TARGET_DEAD (TA panicked)
        _           => EIO,
    }
}

/// Size of the one shared buffer we allocate and reuse.
/// 4 KB is one page and comfortably larger than 64 bytes; there is
/// no reason to be clever here.
const SHM_SIZE: usize = 4096;

// -----------------------------------------------------------------
// The TEE session
//
// ONE session for the whole system, created at probe, guarded by a
// mutex. Every ioctl serialises through it.
//
// Why not a session per open() file? Because OP-TEE has a fixed
// number of threads (chapter 5). A hundred processes each holding a
// session will exhaust them, and the failure mode is the entire
// secure world wedging, not an error return.
// -----------------------------------------------------------------
struct TeeSession {
    ctx:     *mut bindings::tee_context,
    shm:     *mut bindings::tee_shm,
    shm_va:  *mut u8,
    session: u32,
}

// SAFETY: the raw pointers are only ever touched while the enclosing
// Mutex is held, and they remain valid from probe() to remove().
unsafe impl Send for TeeSession {}

impl TeeSession {
    fn new(uuid: &[u8; 16]) -> Result<Self> {
        // SAFETY: passing a null `start` asks for the first matching
        // TEE; `optee_match` is a valid callback.
        let ctx = unsafe {
            tee_client_open_context(
                core::ptr::null_mut(),
                optee_match,
                core::ptr::null(),
                core::ptr::null_mut(),
            )
        };
        // The TEE core returns an ERR_PTR, not null, on failure.
        if kernel::error::from_err_ptr(ctx).is_err() {
            // -ENOENT here means the TEE is not up YET, which during
            // boot is normal. Returning EPROBE_DEFER lets the driver
            // core retry us later.
            pr_info!("rsec: no OP-TEE context yet, deferring\n");
            return Err(EPROBE_DEFER);
        }

        let mut arg = bindings::tee_ioctl_open_session_arg::default();
        arg.uuid.copy_from_slice(uuid);
        arg.clnt_login = bindings::TEE_IOCTL_LOGIN_REE_KERNEL;
        arg.num_params = 0;

        // SAFETY: ctx is valid; no parameters, so a null param array.
        let rc = unsafe {
            tee_client_open_session(ctx, &mut arg, core::ptr::null_mut())
        };
        if rc < 0 || arg.ret != 0 {
            pr_err!("rsec: open_session rc={} ret=0x{:08x}\n", rc, arg.ret);
            // SAFETY: ctx is valid and we are giving it up.
            unsafe { tee_client_close_context(ctx) };
            return Err(EINVAL);
        }

        // SAFETY: ctx is valid.
        let shm = unsafe { tee_shm_alloc_kernel_buf(ctx, SHM_SIZE) };
        if kernel::error::from_err_ptr(shm).is_err() {
            // SAFETY: both handles are valid and we are releasing them.
            unsafe {
                tee_client_close_session(ctx, arg.session);
                tee_client_close_context(ctx);
            }
            return Err(ENOMEM);
        }

        // SAFETY: shm is valid, offset 0 is in range.
        let shm_va = unsafe { tee_shm_get_va(shm, 0) } as *mut u8;

        Ok(Self { ctx, shm, shm_va, session: arg.session })
    }

    /// Build a memref parameter pointing into our shared buffer.
    fn memref(&self, attr: u32, offs: usize, size: usize)
        -> bindings::tee_param
    {
        let mut p = bindings::tee_param::default();
        p.attr = attr as u64;
        // SAFETY: writing the memref arm of the union. `tee_param`
        // is a plain C union of POD types; every arm is valid to
        // write and the TEE core reads the arm named by `attr`.
        unsafe {
            p.u.memref.shm      = self.shm;
            p.u.memref.shm_offs = offs as u64;
            p.u.memref.size     = size as u64;
        }
        p
    }

    fn invoke(&self, func: u32, params: &mut [bindings::tee_param])
        -> Result<()>
    {
        let mut arg = bindings::tee_ioctl_invoke_arg::default();
        arg.func       = func;
        arg.session    = self.session;
        arg.num_params = params.len() as u32;

        // SAFETY: ctx and session are live for the driver's lifetime;
        // `params` is a valid array of `num_params` entries.
        let rc = unsafe {
            tee_client_invoke_func(self.ctx, &mut arg, params.as_mut_ptr())
        };
        if rc < 0 {
            return Err(kernel::error::Error::from_errno(rc));
        }
        if arg.ret != 0 {
            pr_warn!("rsec: TA cmd {} returned 0x{:08x}\n", func, arg.ret);
            return Err(tee_result_to_errno(arg.ret));
        }
        Ok(())
    }
}

impl Drop for TeeSession {
    fn drop(&mut self) {
        // Order matters and is the reverse of construction: buffers,
        // then session, then context. Freeing the context first
        // leaves the TA holding a reference to shared memory that
        // has gone away.
        // SAFETY: all three handles were created in `new` and are
        // still live; this runs once, at remove().
        unsafe {
            tee_shm_free(self.shm);
            tee_client_close_session(self.ctx, self.session);
            tee_client_close_context(self.ctx);
        }
    }
}

#[pin_data]
struct RsecDevice {
    #[pin]
    tee: Mutex<TeeSession>,
}

#[vtable]
impl MiscDevice for RsecDevice {
    type Ptr = Arc<RsecDevice>;

    fn open(_file: &kernel::fs::File, misc: &MiscDeviceRegistration<Self>)
        -> Result<Arc<RsecDevice>>
    {
        // Every open() hands back a reference to the SAME device, and
        // therefore the same TEE session. There is no per-open state.
        Ok(misc.device_data().clone())
    }

    fn ioctl(dev: ArcBorrow<'_, RsecDevice>, _file: &kernel::fs::File,
             cmd: u32, arg: usize) -> Result<isize>
    {
        match cmd {
            RSEC_IOC_PUBKEY  => dev.ioctl_pubkey(arg),
            RSEC_IOC_SIGN    => dev.ioctl_sign(arg),
            RSEC_IOC_COUNTER => dev.ioctl_counter(arg),
            // ENOTTY, not EINVAL: it is what user space expects from
            // an ioctl it does not recognise, and what `strace`
            // prints intelligibly.
            _ => Err(ENOTTY),
        }
    }
}

impl RsecDevice {
    // -------------------------------------------------------------
    // RSEC_IOC_PUBKEY
    // -------------------------------------------------------------
    fn ioctl_pubkey(&self, arg: usize) -> Result<isize> {
        // 1. Copy the request struct in. UserSlice does the
        //    access_ok + copy_from_user, and will not let us
        //    accidentally dereference a user pointer.
        let mut req = RsecPubkey::default();
        let mut reader = UserSlice::new(
            arg as *mut c_void,
            core::mem::size_of::<RsecPubkey>(),
        ).reader();
        reader.read_raw(unsafe {
            core::slice::from_raw_parts_mut(
                &mut req as *mut _ as *mut u8,
                core::mem::size_of::<RsecPubkey>(),
            )
        })?;

        // 2. Validate BEFORE doing anything. Version first.
        if req.version != RSEC_ABI_VERSION {
            return Err(EINVAL);
        }
        if (req.len as usize) < PUBKEY_LEN {
            return Err(ENOSPC);
        }

        // 3. Talk to the TA under the lock.
        let mut key = [0u8; PUBKEY_LEN];
        {
            let tee = self.tee.lock();
            let mut params = [
                tee.memref(
                    bindings::TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_OUTPUT,
                    0, PUBKEY_LEN),
                bindings::tee_param::default(),
                bindings::tee_param::default(),
                bindings::tee_param::default(),
            ];
            tee.invoke(TA_CMD_GET_PUBKEY, &mut params)?;

            // SAFETY: the TA wrote at most PUBKEY_LEN bytes at
            // offset 0 of a buffer we allocated with SHM_SIZE >
            // PUBKEY_LEN, and shm_va is a valid kernel mapping.
            unsafe {
                core::ptr::copy_nonoverlapping(
                    tee.shm_va, key.as_mut_ptr(), PUBKEY_LEN);
            }
        }   // lock released here, before we touch user memory

        // 4. Copy out. NOTE we are no longer holding the mutex:
        //    copy_to_user can fault and sleep, and sleeping with a
        //    lock held that every other caller needs is how you turn
        //    a slow disk into a system-wide stall.
        let mut writer = UserSlice::new(
            req.buf as *mut c_void, PUBKEY_LEN).writer();
        writer.write_slice(&key)?;

        Ok(0)
    }

    // -------------------------------------------------------------
    // RSEC_IOC_SIGN
    // -------------------------------------------------------------
    fn ioctl_sign(&self, arg: usize) -> Result<isize> {
        let mut req = RsecSign {
            version: 0, sig_len: 0, digest: [0u8; 32], sig: 0,
        };
        let mut reader = UserSlice::new(
            arg as *mut c_void,
            core::mem::size_of::<RsecSign>(),
        ).reader();
        reader.read_raw(unsafe {
            core::slice::from_raw_parts_mut(
                &mut req as *mut _ as *mut u8,
                core::mem::size_of::<RsecSign>(),
            )
        })?;

        if req.version != RSEC_ABI_VERSION {
            return Err(EINVAL);
        }
        if (req.sig_len as usize) < SIG_LEN {
            return Err(ENOSPC);
        }

        let mut sig = [0u8; SIG_LEN];
        {
            let tee = self.tee.lock();

            // Digest into shared memory at offset 0,
            // signature comes back at offset 64. One buffer, two
            // regions, addressed with partial memrefs.
            // SAFETY: both regions are inside the SHM_SIZE buffer.
            unsafe {
                core::ptr::copy_nonoverlapping(
                    req.digest.as_ptr(), tee.shm_va, DIGEST_LEN);
            }

            let mut params = [
                tee.memref(
                    bindings::TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_INPUT,
                    0, DIGEST_LEN),
                tee.memref(
                    bindings::TEE_IOCTL_PARAM_ATTR_TYPE_MEMREF_OUTPUT,
                    64, SIG_LEN),
                bindings::tee_param::default(),
                bindings::tee_param::default(),
            ];
            tee.invoke(TA_CMD_SIGN, &mut params)?;

            // SAFETY: offset 64 + SIG_LEN is within SHM_SIZE.
            unsafe {
                core::ptr::copy_nonoverlapping(
                    tee.shm_va.add(64), sig.as_mut_ptr(), SIG_LEN);
            }
        }

        let mut writer = UserSlice::new(
            req.sig as *mut c_void, SIG_LEN).writer();
        writer.write_slice(&sig)?;

        Ok(0)
    }

    // -------------------------------------------------------------
    // RSEC_IOC_COUNTER
    // -------------------------------------------------------------
    fn ioctl_counter(&self, arg: usize) -> Result<isize> {
        let mut req = RsecCounter::default();
        let slice = UserSlice::new(
            arg as *mut c_void,
            core::mem::size_of::<RsecCounter>(),
        );
        let mut reader = slice.reader();
        reader.read_raw(unsafe {
            core::slice::from_raw_parts_mut(
                &mut req as *mut _ as *mut u8,
                core::mem::size_of::<RsecCounter>(),
            )
        })?;

        if req.version != RSEC_ABI_VERSION {
            return Err(EINVAL);
        }

        let value: u64;
        {
            let tee = self.tee.lock();
            let mut p0 = bindings::tee_param::default();
            p0.attr = bindings::TEE_IOCTL_PARAM_ATTR_TYPE_VALUE_INOUT as u64;
            // SAFETY: writing the value arm of a POD union.
            unsafe {
                p0.u.value.a = if req.increment != 0 { 1 } else { 0 };
                p0.u.value.b = 0;
            }

            let mut params = [
                p0,
                bindings::tee_param::default(),
                bindings::tee_param::default(),
                bindings::tee_param::default(),
            ];
            tee.invoke(TA_CMD_COUNTER, &mut params)?;

            // SAFETY: the TA wrote the value arm, which is what we
            // asked for with VALUE_INOUT.
            let (lo, hi) = unsafe {
                (params[0].u.value.a, params[0].u.value.b)
            };
            value = (lo as u64) | ((hi as u64) << 32);
        }

        req.value = value;
        let mut writer = UserSlice::new(
            arg as *mut c_void,
            core::mem::size_of::<RsecCounter>(),
        ).writer();
        writer.write_slice(unsafe {
            core::slice::from_raw_parts(
                &req as *const _ as *const u8,
                core::mem::size_of::<RsecCounter>(),
            )
        })?;

        Ok(0)
    }
}

struct RsecModule {
    _misc: Pin<KBox<MiscDeviceRegistration<RsecDevice>>>,

/// Parse the UUID string from the shared crate into the 16 bytes
/// the TEE core wants, in big-endian "export_uuid" order.
fn parse_uuid(s: &str) -> Result<[u8; 16]> {
    let mut out = [0u8; 16];
    let mut i = 0;
    let bytes = s.as_bytes();
    let mut k = 0;
    while k < bytes.len() {
        if bytes[k] == b'-' { k += 1; continue; }
        if i >= 16 || k + 1 >= bytes.len() { return Err(EINVAL); }
        let hi = (bytes[k] as char).to_digit(16).ok_or(EINVAL)? as u8;
        let lo = (bytes[k + 1] as char).to_digit(16).ok_or(EINVAL)? as u8;
        out[i] = (hi << 4) | lo;
        i += 1;
        k += 2;
    }
    if i != 16 { return Err(EINVAL); }
    Ok(out)
}

impl kernel::Module for RsecModule {
    fn init(_module: &'static ThisModule) -> Result<Self> {
        pr_info!("rsec: initialising\n");

        let uuid = parse_uuid(RSEC_TA_UUID)?;
        let session = TeeSession::new(&uuid)?;

        let dev = Arc::pin_init(
            try_pin_init!(RsecDevice {
                tee <- new_mutex!(session, "rsec::tee"),
            }),
            GFP_KERNEL,
        )?;

        let options = MiscDeviceOptions { name: c_str!("rsec") };
        let misc = KBox::pin_init(
            MiscDeviceRegistration::register(options, dev),
            GFP_KERNEL,
        )?;

        pr_info!("rsec: /dev/rsec ready\n");
        Ok(Self { _misc: misc })
    }
}
Rust-for-Linux APIs move

MiscDevice, UserSlice and the pin_init machinery have all changed shape between 6.8 and 6.13, and will change again. The structure above — one session, one mutex, copy in, validate, invoke, copy out with the lock dropped — is stable; the exact trait signatures are not. Check rust/kernel/miscdevice.rs in the tree you are building against and adjust. This is the current price of admission for Rust in the kernel, and it is worth saying out loud rather than discovering.

// host/src/lib.rs  -  the user-mode driver proper
//
// This is the layer that turns "an ioctl on a file descriptor"
// into an API a program would want to use. Keeping it separate
// from the CLI is what makes it a driver rather than a script.

use std::fs::{File, OpenOptions};
use std::io;
use std::os::unix::io::AsRawFd;

use rsec_abi::*;

pub struct Rsec {
    f: File,
}

impl Rsec {
    pub fn open() -> io::Result<Self> {
        let f = OpenOptions::new()
            .read(true)
            .write(true)
            .open("/dev/rsec")?;
        Ok(Self { f })
    }

    /// # Safety contract we uphold for every ioctl below
    /// `arg` points at a live, correctly-typed struct for `req`,
    /// and the kernel only reads/writes within its declared size.
    unsafe fn ioctl(&self, req: u32, arg: *mut libc::c_void)
        -> io::Result<()>
    {
        let rc = unsafe {
            libc::ioctl(self.f.as_raw_fd(), req as libc::c_ulong, arg)
        };
        if rc < 0 {
            return Err(io::Error::last_os_error());
        }
        Ok(())
    }

    pub fn public_key(&self) -> io::Result<[u8; PUBKEY_LEN]> {
        let mut out = [0u8; PUBKEY_LEN];
        let mut req = RsecPubkey {
            version: RSEC_ABI_VERSION,
            len:     PUBKEY_LEN as u32,
            buf:     out.as_mut_ptr() as u64,
        };
        unsafe {
            self.ioctl(RSEC_IOC_PUBKEY,
                       &mut req as *mut _ as *mut libc::c_void)?
        };
        Ok(out)
    }

    pub fn sign(&self, digest: &[u8; DIGEST_LEN])
        -> io::Result<[u8; SIG_LEN]>
    {
        let mut sig = [0u8; SIG_LEN];
        let mut req = RsecSign {
            version: RSEC_ABI_VERSION,
            sig_len: SIG_LEN as u32,
            digest:  *digest,
            sig:     sig.as_mut_ptr() as u64,
        };
        unsafe {
            self.ioctl(RSEC_IOC_SIGN,
                       &mut req as *mut _ as *mut libc::c_void)?
        };
        Ok(sig)
    }

    pub fn counter(&self, increment: bool) -> io::Result<u64> {
        let mut req = RsecCounter {
            version:   RSEC_ABI_VERSION,
            increment: increment as u32,
            value:     0,
        };
        unsafe {
            self.ioctl(RSEC_IOC_COUNTER,
                       &mut req as *mut _ as *mut libc::c_void)?
        };
        Ok(req.value)
    }
}
// host/src/crypto.rs  -  everything OpenSSL does
//
// Note what is here: hashing, format conversion, verification.
// All public-key or public-data operations. Nothing secret ever
// reaches this file.

use openssl::bn::{BigNum, BigNumContext};
use openssl::ec::{EcGroup, EcKey, EcPoint};
use openssl::ecdsa::EcdsaSig;
use openssl::error::ErrorStack;
use openssl::nid::Nid;
use openssl::pkey::Public;
use openssl::sha::Sha256;

use std::fs::File;
use std::io::Read;

/// SHA-256 a file in 64 KB chunks. Bulk data stays in the normal
/// world - only the 32-byte result crosses into the TEE.
pub fn sha256_file(path: &str) -> std::io::Result<[u8; 32]> {
    let mut f = File::open(path)?;
    let mut h = Sha256::new();
    let mut buf = vec![0u8; 64 * 1024];
    loop {
        let n = f.read(&mut buf)?;
        if n == 0 { break; }
        h.update(&buf[..n]);
    }
    Ok(h.finish())
}

/// Turn the TA's raw 64-byte X||Y into an OpenSSL EC public key.
///
/// The 0x04 prefix marks an UNCOMPRESSED SEC1 point. Forget it and
/// `EcPoint::from_bytes` fails with an error message that does not
/// mention prefixes.
pub fn public_key_from_raw(raw: &[u8; 64])
    -> Result<EcKey<Public>, ErrorStack>
{
    let group = EcGroup::from_curve_name(Nid::X9_62_PRIME256V1)?;
    let mut ctx = BigNumContext::new()?;

    let mut sec1 = Vec::with_capacity(65);
    sec1.push(0x04);
    sec1.extend_from_slice(raw);

    let point = EcPoint::from_bytes(&group, &sec1, &mut ctx)?;
    EcKey::from_public_key(&group, &point)
}

/// The TA emits raw r||s, fixed width. OpenSSL, X.509, TLS and CMS
/// all want an ASN.1 SEQUENCE of two INTEGERs. Converting is four
/// lines; forgetting to is the commonest reason a perfectly correct
/// TA signature "does not verify".
pub fn sig_from_raw(raw: &[u8; 64]) -> Result<EcdsaSig, ErrorStack> {
    let r = BigNum::from_slice(&raw[..32])?;
    let s = BigNum::from_slice(&raw[32..])?;
    // Badly named: it builds a signature from its (r, s) components.
    EcdsaSig::from_private_components(r, s)
}

pub fn verify(digest: &[u8; 32], raw_sig: &[u8; 64],
              key: &EcKey<Public>) -> Result<bool, ErrorStack>
{
    sig_from_raw(raw_sig)?.verify(digest, key)
}

pub fn sig_to_der(raw: &[u8; 64]) -> Result<Vec<u8>, ErrorStack> {
    sig_from_raw(raw)?.to_der()
}

pub fn key_to_pem(key: &EcKey<Public>) -> Result<Vec<u8>, ErrorStack> {
    key.public_key_to_pem()
}
// host/src/main.rs  -  the CLI
use std::process::ExitCode;

mod crypto;
use rsecctl::Rsec;          // src/lib.rs
use crypto::*;

fn hex(b: &[u8]) -> String {
    b.iter().map(|x| format!("{:02x}", x)).collect()
}

fn unhex(s: &str) -> Option<Vec<u8>> {
    if s.len() % 2 != 0 { return None; }
    (0..s.len() / 2)
        .map(|i| u8::from_str_radix(&s[2 * i..2 * i + 2], 16).ok())
        .collect()
}

fn run() -> Result<(), Box<dyn std::error::Error>> {
    let args: Vec<String> = std::env::args().collect();
    let dev = Rsec::open()?;

    match args.get(1).map(String::as_str) {
        Some("pubkey") => {
            let raw = dev.public_key()?;
            println!("raw : 04{}", hex(&raw));
            let key = public_key_from_raw(&raw)?;
            print!("{}", String::from_utf8_lossy(&key_to_pem(&key)?));
        }

        Some("sign") if args.len() == 3 => {
            let d = sha256_file(&args[2])?;
            let sig = dev.sign(&d)?;
            println!("{}", hex(&sig));
        }

        Some("verify") if args.len() == 4 => {
            let d = sha256_file(&args[2])?;
            let raw = unhex(&args[3]).ok_or("bad signature hex")?;
            if raw.len() != 64 { return Err("signature must be 64 bytes".into()); }
            let mut sig = [0u8; 64];
            sig.copy_from_slice(&raw);

            let key = public_key_from_raw(&dev.public_key()?)?;
            // THE PROOF: OpenSSL, which knows nothing about OP-TEE,
            // checks a signature the secure world produced.
            println!("{}", if verify(&d, &sig, &key)? { "VALID" } else { "INVALID" });
        }

        Some("der") if args.len() == 3 => {
            let d = sha256_file(&args[2])?;
            let sig = dev.sign(&d)?;
            std::io::Write::write_all(
                &mut std::io::stdout(), &sig_to_der(&sig)?)?;
        }

        Some("counter") => {
            let inc = args.get(2).map(String::as_str) == Some("inc");
            println!("{}", dev.counter(inc)?);
        }

        _ => {
            eprintln!("usage: rsecctl pubkey");
            eprintln!("       rsecctl sign   <file>");
            eprintln!("       rsecctl verify <file> <sighex>");
            eprintln!("       rsecctl der    <file>   # DER to stdout");
            eprintln!("       rsecctl counter [inc]");
            return Err("bad usage".into());
        }
    }
    Ok(())
}

fn main() -> ExitCode {
    match run() {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => { eprintln!("rsecctl: {e}"); ExitCode::FAILURE }
    }
}

Proving it independently

The same discipline as the earlier project: demonstrate from the outside that the key is unreachable, rather than asserting it.

# Everything above trusted our own code to verify our own code.
# Take the artefacts off the machine and check them with stock
# OpenSSL, which has never heard of OP-TEE.

# On the guest:
# rsecctl pubkey | sed -n '/BEGIN/,/END/p' > /tmp/pub.pem
# rsecctl der /tmp/msg > /tmp/sig.der

# Copy /tmp/pub.pem, /tmp/sig.der and /tmp/msg to the host, then:
$ openssl ec -pubin -in pub.pem -text -noout
Public-Key: (256 bit)
pub:
    04:a9:1f:...
ASN1 OID: prime256v1
NIST CURVE: P-256

$ openssl dgst -sha256 -verify pub.pem -signature sig.der msg
Verified OK

# THAT is the result the whole project exists to produce.
#
# A signature that verifies under a public key, over a digest of a
# file, where the corresponding private key was created inside the
# secure world, has never been present in any page the normal world
# could map, and cannot be extracted by root, by the kernel module,
# or by a kernel exploit.
#
# And the request travelled: Rust user program -> Rust kernel module
# -> SMC -> TF-A -> OP-TEE -> Rust trusted application, and back.

Checking the claim rather than assuming it

A final check that the isolation holds under deliberate attack rather than under normal use — which is the only test that actually validates the design.

# The claim is "the private key is not reachable from the normal
# world". Test it, do not trust it.

# 1. It is not in the module's memory - the module never sees it.
#    Everything the driver copies is 32 or 64 bytes of digest or
#    signature. Grep the source for a private key: there is none.

# 2. Secure storage is opaque from the normal world.
# ls -l /data/tee/
-rw-------    1 root  root  128  0
# xxd /data/tee/0 | head -2
00000000: 8f3a 2c91 e5d7 ...     # AES-GCM ciphertext, keyed from
00000010: 1b44 90ff 7c22 ...     # the HUK (chapter 15)

# 3. The secure DRAM carve-out is fenced. On QEMU:
# devmem2 0x0e100000 w
Bus error                        # correct - see chapter 24

# 4. The TA is single-instance and keep-alive, so its heap - where
#    the loaded key object lives - is never handed back to the
#    normal world's allocator.
# cat /sys/kernel/debug/tee/... 2>/dev/null

# What this does NOT prove, and you should be clear about it:
#   * on QEMU the HUK is a fixed test value, so secure storage is
#     not device-bound (chapter 15). On real silicon it is.
#   * a compromised OP-TEE core, or a TA with a memory bug, still
#     reaches the key. The boundary is only as good as what runs
#     inside it (chapter 20).
#   * physical attacks are out of scope entirely.

If you cannot enable CONFIG_RUST

Rust kernel modules need a recent kernel, a matching rustc, bindgen, and patience. If the kernel you must ship on does not have it, the ABI in rsec-abi is language-neutral — a C module implementing the same three ioctls keeps the Rust TA and the Rust user-mode driver working unchanged.

/* rsec_shim.c - the same driver in C, if you need it.
   Abridged: the ioctl bodies mirror the Rust ones exactly.     */

static long rsec_ioctl(struct file *f, unsigned int cmd,
                       unsigned long arg)
{
        struct rsec_dev *d = f->private_data;
        int rc;

        switch (cmd) {
        case RSEC_IOC_SIGN: {
                struct rsec_sign req;
                u8 sig[64];

                if (copy_from_user(&req, (void __user *)arg,
                                   sizeof req))
                        return -EFAULT;
                if (req.version != RSEC_ABI_VERSION)
                        return -EINVAL;
                if (req.sig_len < 64)
                        return -ENOSPC;

                mutex_lock(&d->lock);
                memcpy(d->shm_va, req.digest, 32);
                rc = rsec_invoke(d, TA_CMD_SIGN, 32, 64);
                if (!rc)
                        memcpy(sig, d->shm_va + 64, 64);
                mutex_unlock(&d->lock);
                if (rc)
                        return rc;

                if (copy_to_user((void __user *)req.sig, sig, 64))
                        return -EFAULT;
                return 0;
        }
        ...
        default:
                return -ENOTTY;
        }
}

/* The point worth taking: because the ABI lives in a crate that
   generates the same numbers a C header would, swapping the middle
   layer's language changes nothing above or below it. That is what
   a frozen ABI is FOR.                                          */
