DP: interval, tree and bitmask

Three state shapes beyond the linear ones. Each is recognisable from the constraints, and each has a fill order that is the whole difficulty.

Interval DP

Interval DP is the variant where the state is a range rather than a position, and the loop order that follows from it is the part people get wrong. Start with the recurrence and the order becomes forced.

   STATE: a RANGE.   dp[i][j] = answer for the segment
                                 a[i..j]

   RECURRENCE: split the range at every possible point and
   take the best.

     dp[i][j] = best over k in (i, j) of
                  dp[i][k] + dp[k][j] + cost(i, k, j)

   THE FILL ORDER IS THE WHOLE TRICK: iterate by INCREASING
   LENGTH, not by increasing i.

     for (len = 2; len <= n; len++)
         for (i = 0; i + len <= n; i++) {
             j = i + len - 1;
             ...
         }

   Filling by rows would read dp[i][k] and dp[k][j] before
   they exist, because both are SHORTER ranges that live on
   later rows or earlier columns.

   COST: O(n^3) — n^2 states, O(n) split points each. Which
   is exactly why the constraint is typically n <= 100..500
   (chapter 02).

   THE FAMILY: burst balloons, matrix chain multiplication,
   minimum cost to merge stones, palindrome partitioning II,
   optimal BST.

   ---------------------------------------------------------
   TREE DP

   STATE: a NODE, usually with a small extra flag.
   The children are the subproblems, so a POSTORDER
   traversal is automatically a valid fill order — no
   ordering work needed (chapter 28).

     function dfs(node) {
         if (!node) return baseCase;
         const L = dfs(node.left), R = dfs(node.right);
         return combine(L, R, node.val);
     }

   THE COMMON SHAPE returns a PAIR: "best if I take this
   node" and "best if I do not". House Robber III is exactly
   that, and so are most tree-selection problems.

   ---------------------------------------------------------
   BITMASK DP

   STATE: a SUBSET, encoded as an integer (chapter 18).

     dp[mask] = answer having already used the items in mask

   2^n states, so it is only viable for n <= 20 or so.
   THAT CONSTRAINT IS THE SIGNAL: if you see n <= 20 and the
   problem is about assignments or orderings, think bitmask.

   THE TWO STANDARD FORMS:

     ITERATE OVER SUBSETS
       for (mask = 0; mask < (1 << n); mask++)
           for (i = 0; i < n; i++)
               if (!(mask & (1 << i)))
                   dp[mask | (1<<i)] = best(dp[mask] + cost)

     TRAVELLING-SALESMAN STYLE — dp[mask][last]
       state also records WHERE you currently are.
       O(2^n * n^2).

   THE FAMILY: assignment problems, TSP, partition into k
   equal subsets, shortest superstring, "can I win this
   game?".

How it shows up

SymptomCause
Interval DP reads zerosFilled by row instead of by increasing length
Burst balloons double-countsThink of the balloon burst last, not first
