Stacks: matching, expressions and design

Last in, first out. Whenever the most recent unresolved thing is the one you need next — a bracket, an operand, an undo step, a recursive call — the structure is a stack.

The pattern

A stack is worth reaching for whenever the problem involves something that must be matched, nested, or deferred until later. The operations are trivial; recognising the shape is the skill.

   THE OPERATIONS, all O(1):
     push(x)   put on top
     pop()     remove and return the top
     peek()    look at the top without removing
     isEmpty()

   IN JAVASCRIPT an array IS a stack:
     st.push(x)      st.pop()      st[st.length - 1]

   THE RECOGNITION SIGNALS:

     NESTING or MATCHING       brackets, tags, nested
                               structures
     "MOST RECENT" matters     undo, back button, call stack
     REVERSE something         a stack reverses order for free
     EXPRESSION EVALUATION     operands and operators
     RECURSION MADE ITERATIVE  the explicit stack IS the call
                               stack (chapter 27)
     NEXT GREATER / SMALLER    a MONOTONIC stack — chapter 23

   ---------------------------------------------------------
   THE MATCHING TEMPLATE, which covers a whole family:

     for (const c of s) {
         if (isOpener(c)) st.push(c);
         else {
             if (st.length === 0) return false;   // nothing to
                                                  // match
             if (!matches(st.pop(), c)) return false;
         }
     }
     return st.length === 0;      // NOTHING LEFT UNCLOSED

   BOTH EMPTINESS CHECKS ARE NEEDED. Popping an empty stack
   means a closer with no opener — ")(" fails here. A
   non-empty stack at the end means an unclosed opener —
   "(((" fails there. Miss either and half the tests pass.

   ---------------------------------------------------------
   EXPRESSION EVALUATION

     POSTFIX (RPN): "3 4 + 2 *"
       push operands; on an operator, pop TWO, apply, push
       the result. ORDER MATTERS for - and /:
         b = pop(); a = pop(); push(a OP b);
       Popping in the wrong order silently breaks subtraction
       and division while addition still passes.

     INFIX with precedence: two stacks (operands and
     operators), or the shunting-yard algorithm. Rare in
     interviews; the postfix version is the common one.
